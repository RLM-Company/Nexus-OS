# Stream Lab

Локальная панель для сравнения потоковых ответов. Из корня репозитория выполните:

```powershell
pnpm --filter @cosmora/model-gateway... -r run build
node scripts/stream-speed-panel.mjs
```

Откройте [Stream Lab](http://127.0.0.1:4178/). Фикстура работает сразу. Выберите нужные режимы и отправьте один запрос. Выбранные маршруты выполняются последовательно с одинаковым текстом и ограничением выхода. Каждый выбранный живой маршрут отправляет один запрос.

| Маршрут | Переменные окружения                                                                                                                                                        |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обычный | `MODEL_BASE_URL`, `MODEL_NAME`, `MODEL_API_KEY`                                                                                                                             |
| Быстрый | `SPEED_FAST_MODEL` использует обычный API. Для другого провайдера также задайте `SPEED_FAST_BASE_URL` и `SPEED_FAST_API_KEY`.                                               |
| Разгон  | `SPEED_ACCEL_BASE_URL`, `SPEED_ACCEL_MODEL`, `SPEED_ACCEL_API_KEY`. Для локального HTTP на loopback ключ опционален. Здесь подключается отдельный OpenAI-совместимый стенд. |

Режим «Быстрый» обозначает отдельный настроенный маршрут. Для всех режимов локальный HTTP разрешён на loopback, ключ там опционален. Для сравнения обычного декодирования с разгоном используйте одну целевую модель и одинаковые настройки на серверах. Панель показывает время до первого видимого текста, полное время, наблюдаемые символы в секунду между видимыми фрагментами и сообщённые провайдером выходные токены. Скорость по токенам считается за весь запрос и может включать скрытое рассуждение. Фикстура служит для проверки панели.

Запуск привязан к `127.0.0.1`. Настройки и ключи берутся из окружения процесса. Для другого порта задайте `SPEED_PANEL_PORT`.

## Эксперименты с Hy4 Flash через API

Настройте обычный маршрут с `MODEL_NAME=hy4flash` и подключите нужные эксперименты.

- `SPEED_FAST_REQUEST_TIER=1` добавляет `service_tier: "fast"` к запросу. По умолчанию проба использует базовый маршрут и запускается по явному выбору в панели. HTTP 200 сам по себе не подтверждает выбор тарифа. Уточните подтверждение и списания у провайдера.
- `SPEED_ACCEL_DIRECT_ANSWER=1` использует базовый маршрут и добавляет системную инструкцию сразу дать ответ на простой запрос. Эксперимент проверяет время до видимого ответа и соблюдение формата. Параметры серверного декодирования при этом не меняются.

Сравнивайте режимы с одним текстом и лимитом выхода. Меняйте порядок прогонов между повторами. Проверяйте правильность, соблюдение формата и долю завершённых ответов вместе со временем. Пробу тарифа оценивайте отдельно по подтверждению провайдера и списаниям.

### Первый прогон CheapVibeCode

Один запрос на режим и задачу, лимит выхода 768 токенов. Все шесть ответов в сравнении обычного и прямого режимов завершились и прошли проверку формата и содержания.

| Задача               | Обычный, первое слово / полный ответ | Прямой, первое слово / полный ответ |
| -------------------- | ------------------------------------ | ----------------------------------- |
| Три совета           | 3,96 / 4,15 с                        | 3,12 / 3,29 с                       |
| Исправление опечатки | 4,83 / 5,08 с                        | 2,95 / 3,17 с                       |
| JSON-массив          | 2,43 / 2,56 с                        | 2,00 / 2,13 с                       |

Медиана по трём задачам уменьшилась с 3,96 до 2,95 с до первого текста и с 4,15 до 3,17 с до полного ответа. Выборка показывает задержку на коротких ответах. Для вывода о скорости генерации токенов нужны более длинные ответы и повторные прогоны.

Проба Fast на задаче с тремя советами дала 4,28 / 4,52 с. Статус тарифа и списание остались неподтверждёнными. В отдельной паре запросов с лимитом 512 токенов параметр `thinking: { type: "disabled" }` через этот API не остановил рассуждения. Оба запроса исчерпали лимит до первого видимого текста.
