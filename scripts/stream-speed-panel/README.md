# Stream Lab

Локальная панель для сравнения потоковых ответов. Из корня репозитория выполните:

```powershell
pnpm --filter @cosmora/model-gateway... -r run build
node scripts/stream-speed-panel.mjs
```

Откройте [Stream Lab](http://127.0.0.1:4178/). Фикстура работает сразу. Выберите нужные режимы и отправьте один запрос. Выбранные маршруты выполняются последовательно с одинаковым текстом и ограничением выхода. Каждый выбранный живой маршрут отправляет один запрос.

| Маршрут | Переменные окружения                                                                                                                                                        |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обычный | `MODEL_BASE_URL`, `MODEL_NAME`, `MODEL_API_KEY`                                                                                                                             |
| Быстрый | `SPEED_FAST_MODEL` использует обычный API. Для другого провайдера также задайте `SPEED_FAST_BASE_URL` и `SPEED_FAST_API_KEY`.                                               |
| Разгон  | `SPEED_ACCEL_BASE_URL`, `SPEED_ACCEL_MODEL`, `SPEED_ACCEL_API_KEY`. Для локального HTTP на loopback ключ опционален. Здесь подключается отдельный OpenAI-совместимый стенд. |

Режим «Быстрый» обозначает отдельный настроенный маршрут. Для всех режимов локальный HTTP разрешён на loopback, ключ там опционален. Для сравнения обычного декодирования с разгоном используйте одну целевую модель и одинаковые настройки на серверах. Панель показывает время до первого видимого текста, полное время, наблюдаемые символы в секунду между видимыми фрагментами и сообщённые провайдером выходные токены. Скорость по токенам считается за весь запрос и может включать скрытое рассуждение. Фикстура служит для проверки панели.

Запуск привязан к `127.0.0.1`. Настройки и ключи берутся из окружения процесса. Для другого порта задайте `SPEED_PANEL_PORT`.

## Первый эксперимент с разгоном генерации

Панель сравнивает маршруты. Генерация и проверка предложенных токенов выполняются на сервере модели. На внешнем API доступны только режимы, которые предоставляет сам провайдер. Адаптивная маршрутизация Kosmora относится к отдельной функции.

1. Начать с локального `llama.cpp` на CPU и небольшой квантованной модели. Для первого опыта использовать одну целевую модель и два режима: обычное декодирование и `ngram-simple`. N-граммы берут кандидатов из текущего контекста. Для этого варианта отдельная модель не требуется. [Документация llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/docs/speculative.md)
2. Подключить режимы к «Обычный» и «Разгон». Сохранить одинаковый файл весов, контекст, шаблон сообщения, параметры потоковой выдачи, потоки CPU, предел выхода и детерминированное декодирование. Сравнивать на одном рабочем процессе за раз или убедиться, что неактивный процесс простаивает и оба набора данных помещаются в память.
3. Для разведки взять три запроса: преобразование повторяющихся данных, правка текста и свободное объяснение. Прогреть обе конфигурации, затем чередовать порядок запусков и повторить каждую пару три раза. Сравнить токены/с по данным серверного декодирования, время до первого видимого текста, полное время и совпадение ответа при детерминированных настройках. Записывать принятые и предложенные токены, если сервер предоставляет эти счётчики.
4. Первый сигнал успеха — хотя бы 20% прироста медианной скорости декодирования на одном классе задач без ухудшения результата. Повторить победивший сценарий и добавить запросы без повторов, чтобы обнаружить накладные расходы. Следующий эксперимент — маленькая черновая модель и разные размеры пачек кандидатов.

Собственная разработка начинается с адаптивного управления размером пачки. Начинать с короткой пачки, увеличивать её там, где кандидаты регулярно проходят проверку, и отключать спекуляцию при низком принятии или перегрузке. Сравнить с обычным декодированием и фиксированным размером. Результат исследования на T5-XXL составлял 2–3× в условиях авторов. Он задаёт ориентир для эксперимента. [Работа Leviathan et al.](https://proceedings.mlr.press/v202/leviathan23a.html)
