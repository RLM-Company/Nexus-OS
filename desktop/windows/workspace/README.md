# Рабочая папка Koswork

Принятый и доработанный пакет Gemini от 29 октября 2026 года. В Windows-клиенте
подключён через `computer-workspace.cjs` к нативной консоли и агентному циклу ПК.
Веб-страница не получает прямого файлового IPC. Shell/скрипты модуль не запускает.

## Использование в приложении

1. Открыть нативную консоль управления компьютером и выбрать проект.
2. Нажать «Выбрать рабочую папку» и выбрать каталог в диалоге Windows.
3. Указать задачу и подтвердить нативный запуск. Текстовые файлы, которые агент
   читает для задачи, могут передаваться модели. Все записи требуют отдельного
   подтверждения и перепланирования по свежему наблюдению.
4. «Отключить папку» немедленно отзывает файловый доступ и останавливает задачу,
   даже если сеть или вход недоступны. Закрытие консоли, смена аккаунта/сервера
   также отзывают доступ. Папка не подключается автоматически при перезапуске.

Модель получает только имя и непрозрачный ID папки, относительные пути и ответы
запрошенных файловых операций. Полный путь не включается в файловые ответы;
он всё ещё может быть виден на обычном снимке экрана, разрешённом владельцем.

## Доступные операции

| Команда агента      | Назначение                                                |
| ------------------- | --------------------------------------------------------- |
| `workspace_list`    | До 30 элементов каталога за страницу, ограниченный курсор |
| `workspace_find`    | Поиск по имени или тексту, до 15 результатов              |
| `workspace_read`    | Полный UTF-8 файл до 10 000 байт                          |
| `workspace_mkdir`   | Создать папку внутри выбранного каталога                  |
| `workspace_create`  | Создать новый текстовый файл без перезаписи               |
| `workspace_update`  | Заменить полный текст при совпадении `expected_version`   |
| `workspace_backups` | Получить версии резервных копий указанного файла          |
| `workspace_restore` | Восстановить указанную копию с проверкой текущей версии   |

Содержимое создания/замены — до 10 000 символов. Полный JSON результата ограничен
15 000 символов; при переполнении возвращается ошибка без обрезанного JSON или
частичного содержимого. Большие файлы нужно обрабатывать другим инструментом;
редактировать их по усечённому чтению запрещено. Бинарные Word/PDF/изображения этот
модуль не создаёт: для управления их приложениями существует обычный исполнитель ПК.

## Внутренний модуль

`createKosworkWorkspaceService` предоставляет чтение, поиск, создание, версионную
запись и копии. В приложении обязательно `requireOwnerScope: true` и явные
`ownerId`/`origin` в каждом обращении. Значение по умолчанию без scope существует
только для локальных тестовых/операторских сценариев и не используется IPC.
Проверка `ipcEvent` внутри модуля сама по себе не заменяет точную проверку окна,
главного фрейма и пакетной страницы, реализованную нативной консолью.

Пути проверяются на выход за корень, абсолютные/UNC пути, ADS, зарезервированные
Windows-имена, неоднозначные разделители Unicode, известные секреты и служебные
каталоги. Символические ссылки, junction и обычные жёсткие ссылки файлов
отклоняются. Это не полноценная песочница против другого процесса с правами того же
пользователя и не гарантия распознавания всех видов reparse points/всех секретов.
Короткие 8.3 пути Windows допускаются после проверки компонентов и канонизации.

Перед заменой проверяется SHA-256 и сохраняется проверенная копия. После записи
файл читается обратно для сверки хеша. Известный конфликт до записи можно сообщить
модели для нового чтения; неизвестный исход после ввода останавливает задачу и
остаётся неопределённым в журнале. Восстановление задачи требует той же папки,
нового согласия, нового серверного сеанса и свежего наблюдения.

## Копии и приватность

В приложении индекс и содержимое копий зашифрованы Windows `safeStorage` в
`userData/koswork-backups/<scope>/`. Подключение папки и разрешение не сохраняются
на диск. Формат копий содержит область и ID, проверяемые после расшифровки;
подмена индексом другой папки или произвольным именем blob отклоняется.
Повреждённый индекс не превращается молча в пустой.

Прямой модуль без `codec` может использовать незашифрованные копии **только для
локальных тестов/операторского использования**. Приложение требует codec, без
незашифрованного fallback. Квота — до 50 копий / 25 МиБ исходного содержимого на
папку; размер шифротекста больше. Это не глобальная квота всего профиля.
Копии сохраняются после обычного отключения, чтобы их можно было восстановить при
повторном выборе той же папки. Явный выход из аккаунта/смена сервера удаляют все
управляемые локальные копии, оставляя рабочие файлы пользователя. Они не входят в
серверный экспорт и не могут мгновенно удаляться сервером с офлайн-устройства.

## Проверка без управления рабочим столом

`node --test desktop/windows/test/koswork-workspace.test.cjs`

`node --test desktop/windows/test/computer-workspace.test.cjs`

`node desktop/windows/workspace/demo.cjs`

Только новые временные папки ОС, подставные модель и наблюдение. Демо не является
доказательством работы живой модели, установленного клиента или сервера.
