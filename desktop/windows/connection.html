Cosmora for Windows

Подключение к Cosmora

Адрес сервера сохранится на этом компьютере. Логин и пароль по умолчанию живут только до закрытия приложения; при желании их можно зашифрованно сохранить средствами Windows.

Удалённые адреса работают только по HTTPS. Проверка сертификата не отключается. При временном обрыве клиент пытается восстановить соединение автоматически.
