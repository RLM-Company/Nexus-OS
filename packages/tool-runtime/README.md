# @nexus/tool-runtime

Единственная разрешённая точка вызова внешних инструментов Synmetis AI.

Перед вызовом обработчика runtime:

1. самостоятельно выводит capability ID из зарегистрированного инструмента;
2. загружает профиль проекта и активные Permission Contract из SQLite;
3. вызывает детерминированный Policy Engine;
4. требует от инструмента явно проверить ограничения для `ALLOW_WITH_LIMITS`;
5. создаёт запрос подтверждения либо атомарно резервирует операцию;
6. передаёт инструменту исходный idempotency key и полный verdict;
7. сохраняет результат или состояние неопределённого сбоя.

Прямой обход `GuardedToolRuntime` для внешнего действия запрещён архитектурным контрактом.

`RESERVED` после аварийного завершения не исполняется повторно автоматически: сначала требуется
сверка с внешним провайдером по idempotency key. Это исключает дублирование публикаций, платежей и
сообщений.
