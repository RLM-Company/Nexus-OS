## Интеграция 27 октября: новые API без изменения интерфейса

- Панели Mission Control, Playbooks, Schedules, Evaluations и Knowledge Vault:
  использовать новые `/projects/:projectId/automation` API. Миссия — существующий
  Work DAG, а не второй исполнитель. У расписаний явный tick и отдельный старт
  владельцем; интерфейс должен честно показывать эту границу.
- Обновление цитаты, выбор нового фрагмента, использование источников и сравнение
  двух аудитов графа: исходные UI-компоненты сохранены в ветках
  `codex/graph-citation-refresh-20261025`, `codex/graph-source-usage-20261026`,
  `codex/graph-evidence-comparison-20261026`. Чистая логика перенесена в Core,
  серверные preview/source-usage/evidence-comparison подключены; панели пока не меняем.
- Панель `/pay` и ссылка из control-center из PR402: отложены. На сервере доступен
  статус выключенного checkout, но публичные платежи, подписки и эквайринг не включены.
- Управление техническими аккаунтами из PR401: будущая панель использует MFA-gated
  API suspend/restore и отдельный журнал с целевым аккаунтом, исполнителем и причиной.

## Финансовая сводка 28 октября

Подключить `GET /api/v1/personal-settings/usage/finance` к аналитике аккаунта в
будущем дизайн-проходе. Показывать расчётные суммы отдельно по валютам, неизвестную
стоимость, фактические токены и незавершённые резервы. `recorded_calculation` не
называть счётом провайдера или подтверждённым списанием; неизвестное не показывать
нулём. Квота остаётся отдельным консервативным счётчиком. Сейчас экран не меняется.

## Частичный результат Koswork / Coscode, 28 октября

В будущей панели восстановления показывать `output_checkpoint` отдельно от
готового плана, файла и проверенного патча. Это непроверенный префикс до 32 КиБ:
показывать обрезку, время сохранения и завершённость потока; последняя не означает
успешную проверку. Ошибку `TASK_TIME_BUDGET` отличать от ручной отмены. Не добавлять
автоматический повтор платного запроса, исполнение или публикацию из этого текста.
Текущие экран чата, сайдбар, стили и Windows-клиент не меняем.
