# Функции Kosmora и Koswork: предложение для совместного разбора

Укрупнённая таблица ниже дополнена
[подробным сравнением рабочих продуктов](KOSWORK_COMPETITIVE_DEEP_DIVE_2026-10-28_RU.md):
среды исполнения, браузер/ПК, интеллект, интеграции, результаты и автоматизация.

28 октября 2026, Europe/Moscow. Статус: проект, не согласованный объём реализации.
Назначение режимов утверждено владельцем в KOSMORA_KOSWORK_BRIEF_RU.md. Здесь
предложены конкретные возможности и собственные идеи. Часть базы уже существует;
по каждой выбранной строке отдельно проверяем код и определяем, что добавить,
исправить или подключить к интерфейсу. Проценты готовности строк не присваиваются.
Multi-Agent исключён. Runtime, UI и сервер этим документом не меняются.

## Kosmora — повседневный бесплатный чат

| ID  | Функция                   | Целевое поведение                                                                                            |
| --- | ------------------------- | ------------------------------------------------------------------------------------------------------------ |
| K01 | Общение и короткие задачи | Естественная беседа, объяснения, идеи, переводы, письма и простые тексты; ответ подходящей длины             |
| K02 | Учебный помощник          | Выбор: объяснить тему, дать подсказку, разобрать решение, проверить собственный ответ                        |
| K03 | Правка выбранного текста  | Переписать выделенный фрагмент, изменить тон/объём, показать новую версию и сохранить исходную               |
| K04 | Файлы и изображения       | Прикрепить материал, прочитать текст/скриншот, пересказать или ответить; явно обозначить непрочитанные части |
| K05 | Поиск в интернете         | Актуальные сведения, ссылки на источники и даты; отдельное понятное действие для поиска                      |
| K06 | Голос и изображения       | Диктовка, озвучка и явный запрос генерации; доступность и отдельные квоты согласовать                        |
| K07 | История и версии          | Поиск сообщений, правка запроса, повтор ответа и ответвление беседы с сохранением прежнего варианта          |
| K08 | Управляемая память        | Просмотр, изменение и удаление сохранённых предпочтений; временная беседа не пополняет долговременную память |
| K09 | Понятный бесплатный лимит | Остаток, время обновления и объяснение расхода; незавершённый текст пользователя сохраняется при исчерпании  |
| K10 | Переход в Koswork         | Передать цель, выбранную историю и материалы; показать границы задачи перед более затратным выполнением      |

Размеры файлов, период и размер бесплатной квоты, учёт разных видов токенов,
доступность моделей и медиа в бесплатном тарифе пока не определены. Временная
беседа не означает отсутствия всех технических журналов; политику хранения
необходимо явно сформулировать. Уменьшение расхода не должно давать бессмысленно
короткие ответы, скрывать потерю контекста или отбрасывать вложения без уведомления.

## Koswork — задачи с готовым результатом

| ID  | Функция                         | Целевое поведение                                                                                                    |
| --- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| W01 | Задание и критерии результата   | Зафиксировать цель, входы, формат результата, ограничения и то, как проверить готовность                             |
| W02 | План работы                     | Видимые шаги; владелец может поправить план и приоритеты до и во время выполнения                                    |
| W03 | Компьютер агента                | Изолированная среда с рабочими файлами и выполнением команд; формат размещения согласовать                           |
| W04 | Рабочий браузер                 | Открывать сайты, читать, заполнять формы, использовать разрешённые сессии; передавать управление пользователю        |
| W05 | Рабочие приложения              | Подключения к выбранным сервисам: источники и разрешённые действия; перечень первых интеграций согласовать           |
| W06 | Материалы проекта               | Папка материалов, инструкции, принятые решения, версии и поиск с указанием источников                                |
| W07 | Документы, таблицы, презентации | Создавать и изменять реальные редактируемые файлы; проверять структуру, формулы и экспорт                            |
| W08 | Исследования                    | Сравнивать источники, отмечать даты и противоречия, связывать выводы с доказательствами                              |
| W09 | Вычисления и обработка файлов   | Расчёты и преобразования кодом в изоляции, с проверкой результата; разработка репозитория остаётся предметом Coscode |
| W10 | Корректировки на ходу           | Учитывать новые указания без ненужного перезапуска уже принятой части работы                                         |
| W11 | Долгие задачи                   | Облачное продолжение, пауза, отмена, восстановление состояния и явный разбор неизвестного исхода                     |
| W12 | Изменения и история результата  | Предпросмотр, версии и сравнение; восстановление обратимых файловых изменений, отдельный учёт внешних действий       |
| W13 | Самостоятельность и доступы     | Согласованные границы: ресурсы, инструменты, бюджет и действия; понятная причина остановки                           |
| W14 | Повторяемые процессы            | Сохранить полезную процедуру и параметры; отдельно настроить запуск вручную, по времени или событию                  |

Доступ к локальному компьютеру пользователя — отдельное подключение, а не
следствие наличия компьютера агента. Windows-приёмка остаётся отложенной.
Откат файла не равен отзыву отправленного письма, платежа или публикации.
Облачная работа требует соответствующего runtime; локальная среда не может
продолжать выполнять действия на выключенном устройстве.

## Скрытые механизмы

| ID  | Механизм                     | Зачем он нужен                                                                                             |
| --- | ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| I01 | Управление контекстом        | Подбирать релевантную историю, сохранять решения, верно различать память, инструкции и материалы           |
| I02 | Выбор глубины и инструментов | Применять достаточную для задачи глубину; сначала подходящий API/код, затем браузер или экран              |
| I03 | Учёт и ограничения           | Учитывать подтверждённый расход, сохранять неопределённый отдельно, применять выбранные лимиты до отправки |
| I04 | Надёжное состояние задачи    | Сохранять шаги и результаты, переживать рестарт, предотвращать дубли запросов и повтор внешних действий    |
| I05 | Работа с источниками         | Привязывать выводы к конкретным материалам/версиям, отмечать отсутствие данных и устаревание               |
| I06 | Проверка результата          | Проверять файл/формулы/расчёт/действие подходящим способом; отмечать непроверенное                         |
| I07 | Изоляция и доступы           | Разделять пользователей, проекты и секреты; внешние страницы и файлы считать данными, а не полномочиями    |

Часть этих механизмов входит в первый этап. Здесь требуется аудит их связи
с новыми сценариями, а не создание дублирующих хранилищ и исполнителей.
Авторетранслятор из прежнего списка идей сохраняется как выключенный по умолчанию
эксперимент: влияние на токены, качество и задержку нужно измерять, гарантированной
экономии для любой модели и языка не заявлять.

## Собственные идеи для выбора владельцем

| ID  | Идея                                  | Пользовательский пример                                                                                    |
| --- | ------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| X01 | Перенос задачи с выбранным контекстом | Обсудить поездку в Kosmora, передать даты и требования в Koswork для подготовки маршрута                   |
| X02 | Память принятых решений               | Закрепить бюджет и требования; новое предложение о смене решения показать явно                             |
| X03 | Ответвление от рабочего состояния     | Проверить другую гипотезу с копией материалов и сравнить результаты; один агент, без Multi-Agent           |
| X04 | Карта результата                      | У каждого важного вывода доступны источник, выполненная проверка и отмеченные ограничения                  |
| X05 | Изменение по зависимостям             | Поменять исходную цифру и обновить затронутые расчёты/разделы, сохранив остальной результат                |
| X06 | Предварительная оценка выполнения     | До начала сравнить варианты по плану, инструментам и ожидаемому расходу; оценку не выдавать за точную цену |

Это потенциальные сильные стороны, а не доказанная уникальность. Некоторые
аналоги и отдельные элементы уже встречаются у конкурентов.

## Рекомендуемый порядок совместного разбора

1. Kosmora: K01–K05, затем K07–K09; доступность K06 обсудить с квотами.
2. Определить одну сквозную задачу Koswork и её готовый результат: W01–W09.
3. Довести управление и восстановление: W10–W13, I01–I07 и переход K10.
4. Выбрать собственные идеи X01–X06 и процессы W14 для следующего расширения.
5. Остальные разделы — по отдельному решению владельца; Multi-Agent последним.

Перед каждой реализацией владелец уточняет сценарии и объём. Для выбранных строк
готовятся фактический аудит текущего кода, критерии приёмки и согласованный план.
