## Вывод

K01 и K04 в основном реализованы. Реальный пробел среза — **K05** (поиск не
подключён к Kosmora-чату) и **K02/K03** (нет явных действий над текстом:
объяснить, переписать выделенное). Всё три — это один механизм «явное действие
над запросом», без нового движка, модели или хранилища.

## Предлагаемый объём (на согласование)

1. **K05 — поиск в Kosmora-чате.** Явное действие «Искать в интернете» у
   сообщения. Использует существующий `WebSearch`. Результаты попадают в
   пользовательское сообщение как **цитируемые данные** (URL, даты), не как
   инструкции; правило уже есть в `CONTEXT_MEMORY_RULES`-подобном стиле для
   памяти. Лимит запросов за сообщение (предложение: 3), учёт в существующем
   расходе, ссылки открываются владельцем. Поиск не включается сам по себе —
   только по явному действию.
2. **K02/K03 — действия над текстом.** Один параметр действия у запроса:
   `explain | hint | walkthrough | check | rewrite` (+ тон/объём для rewrite).
   Никакой новой модели. Выделенный текст для rewrite передаётся вместе с
   запросом; исходный текст сохраняется в истории рядом с новой версией.
   Элементы управления — компактные действия у выделения и у поля ввода,
   без изменения сайдбара/чата.
3. **K04 — честная граница чтения.** Уточнение после проверки кода: усечения
   больших вложений в чате нет, `boundedText` отклоняет файл с явной ошибкой.
   Добавлять поле не нужно. Вместо этого — регрессионный тест на то, что
   oversized-вложение не превращается в тихо обрезанный текст, и правка
   пользовательского сообщения об ошибке, если она не называет лимит.

## Что не входит в этот срез

- K06 (голос/генерация изображений) — после отдельного решения по квотам.
- K07–K09 (версии, память, бесплатный лимит) — следующий разбор.
- Провайдер HY4, тарифы, квоты, модель прав — не трогаем.
- Оболочка: сайдбар, начальный экран, логотип, палитра — без изменений.

## Критерии приёмки (черновик)

- Поиск запускается только явным действием; ответ без действия не тратит поиск.
- Результаты поиска: источник, URL, дата; неудачный поиск — явная ошибка, а не
  выдуманные ссылки.
- Rewrite/учебные режимы не создают новых хранилищ; исходный текст сохраняется.
- Большие вложения: непрочитанные части помечены, модель об этом знает.
- Существующие сценарии чата, памяти и Research не меняют поведения
  (тесты до/после).
