на будущее и использовать материалы при подготовке курса по ИИ. Первым блоком

замерами Kosmora. Внешние статьи, видео и сервисы не входят в архив автоматически.

## Что используем и когда

| Направление                      | Что берём                                                                                                                                             | Решение                                                                 |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Экономия контекста               | Не повторять буквальную цитату, аккуратно сворачивать перекрывающиеся выдержки одного оригинала, выбирать необязательные сведения под вопрос и бюджет | Реализуем сейчас на существующей памяти                                 |
| Проверка результата оптимизации  | Точные байты JSON, покрытие исходных цитат, сохранность ссылок и обязательных требований                                                              | Бесплатный локальный benchmark и регрессии в текущем блоке              |
| Долговременная память            | Усилить происхождение фактов, различие гипотез и подтверждений, актуальность и исправления; опираться на уже существующую память                      | Следующий кандидат; объём отдельно с владельцем                         |
| Документы и RAG                  | Структура сложных документов, достаточность источников, ответы по нескольким материалам                                                               | Позже; библиотека и проверка буквальных цитат уже есть                  |
| Выбор SQL / документов           | Точные расчёты по таблицам плюс пояснения по источникам                                                                                               | Позже: сначала ограниченный сценарий, чтение и лимиты запросов          |
| Отложенная загрузка инструментов | Реестр и загрузка схем по необходимости, большие результаты вне основного контекста                                                                   | Позже: отдельный протокол получения полных результатов и отмены         |
| Поиск по коду                    | Выбирать файлы по задаче, привязывать объяснения к коммиту и строкам                                                                                  | Будущий блок Coscode, без переключения на него сейчас                   |
| Браузер и MCP                    | Семантические действия, узкие права подключения, восстановление после сбоя                                                                            | Расширять наш исполнитель; не создавать второй параллельный стек        |
| Рабочие процессы                 | Условия, преобразования, сохранённые подтверждения и возобновление                                                                                    | Использовать существующие Work DAG и сценарии; новые случаи согласовать |
| Трассировка и оценки             | Сопоставимые задачи, качество, расход, время до первого токена, итоговые артефакты                                                                    | Текущий benchmark — узкая база; общий набор задач позже                 |
| Бизнес-сценарии                  | Встреча → поручения, документы → отчёт, продажи → сводка, мониторинг бренда                                                                           | Резерв нишевых сценариев Koswork                                        |
| Аудио и видео                    | Таймкоды, говорящие, решения, аудиоверсия выбранных материалов                                                                                        | Позже: отдельные качество, стоимость и права                            |
| Синтетические данные             | Наборы для демонстраций и проверок без реальных пользовательских записей                                                                              | Локальные синтетические примеры сейчас; генератор таблиц позже          |
| Обучение моделей                 | Узкие навыки на доступных открытых весах, собственный контрольный набор                                                                               | Исследовательский резерв; закрытая API-модель от этого не обучается     |
| Multi-Agent                      | Сравнить подходы к координации, бюджетам и завершению                                                                                                 | Последний раздел согласно решению владельца                             |

Это очередь идей, а не обещание реализации всех строк. Новые продуктовые блоки
проходят [согласованный второй этап](STAGE_TWO_WORKFLOW_RU.md).

## Реализованный первый блок

Идея экономного контекста из `run-jev-inside-agent-harness` адаптируется к нашей
существующей архитектуре. Чужой исполнитель и платный сервис не переносятся.

- В передаваемом пакете убирается второй экземпляр цитаты, если `source.quote`
  буквально совпадает с `text`. Исходная запись в БД остаётся полной.
- Покрытые фрагменты истории сворачиваются только при совпадении ссылки,
  версии, исходного хеша, роли и остальных значимых метаданных. Независимые
  источники, различные числа и разные типы памяти не склеиваются по похожести.
- Маленькое обязательное требование не заменяется большим необязательным
  фрагментом: такая замена могла бы создать ложную нехватку контекста.
- Обязательные записи идут первыми. Остальные ранжируются по совпадениям с
  текущим вопросом; учитываются и короткие числовые значения. Это лексический
  поиск, не доказательство истинности или смысловой эквивалентности.
- Сохраняются точный общий бюджет JSON, исходный текущий вопрос и отказ до
  модели, если обязательные требования действительно не помещаются.
- Подключение: обычный/фоновый чат, стадии Manager Work, локальный агент в
  `execution_mode=work`. Самостоятельные browser/computer новых разрешений не получают.
- Дополнительных модельных запросов, embedding-сервиса, миграций и изменений
  интерфейса нет. Полное восстановление всех деталей из ограниченного пакета
  не обещается: оригиналы сохраняются отдельно.

Команда проверки: `pnpm bench:context-selection`. Она строит пакеты и запускает
синтетические случаи без модели, сети, базы пользователя и секретов. Процент
сокращения байтов на примере с намеренными повторами нельзя выдавать за
гарантированную экономию денег или токенов на любой переписке.

## Резерв для курса по ИИ

Курс пока не пишем и не публикуем. Архив — исследовательская база, не готовый
авторский учебник. Предлагаемая структура и упражнения:

| Модуль                                 | Материал из Hub                                                                        | Практическая работа                                                                             |
| -------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 1. Как устроено ИИ-приложение          | Простые чаты, streaming, structured output                                             | Собрать маленькое приложение и обработать неполный ответ                                        |
| 2. Контекст и память                   | `context-engineering-workflow`, `zep-memory-assistant`, `run-jev-inside-agent-harness` | Измерить повторяющийся контекст, сохранить числа и источники, разобрать опасное удаление памяти |
| 3. Документы и доказательства          | `notebook-lm-clone`, `corrective-rag`, `rag-sql-router`                                | Ответить по документам с проверяемыми цитатами и показать недостаток данных                     |
| 4. Агент и исполнитель                 | `build-code-harness`, `open-agent-builder`                                             | Изменить файл, проверить его в том же checkout, пережить отмену и перезапуск                    |
| 5. Браузер, MCP и подключения          | `web-browsing-agent`, `mindsdb-mcp`                                                    | Выполнить разрешённое чтение, отделить данные страницы от инструкций                            |
| 6. Оценка качества и затрат            | `eval-and-observability`, сравнения моделей                                            | Воспроизводимый набор задач, реальные метрики и разбор ошибочных выводов                        |
| 7. Практика для бизнеса                | Встречи, аналитика продаж, мониторинг бренда                                           | Получить законченный проверяемый артефакт для одной конкретной задачи                           |
| 8. Обучение и собственные эксперименты | Fine-tuning, GRPO, синтетические данные                                                | Выбрать узкий навык, отделить обучение от теста и измерить результат                            |

Для каждого урока нужны свои объяснения и примеры, зафиксированные версии,
инструкции воспроизведения, критерии результата и разбор ошибок. Если используется
MIT-код, сохраняем copyright и лицензию. У PDF, данных, изображений, моделей и
внешних материалов проверяем собственные условия отдельно. Упоминание библиотеки
в архиве не подтверждает её актуальный API или условия сервиса.
