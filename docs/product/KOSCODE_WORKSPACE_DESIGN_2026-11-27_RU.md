# Koscode: отдельное пространство разработки

Точечный запрос владельца от 27 ноября 2026: изучить отличия кодовых рабочих
пространств ChatGPT/Codex и Claude Code от обычного чата и адаптировать Koscode,
в первую очередь боковую панель. Это разрешение относится к Koscode.
Сайдбар и стартовый экран Kosmora/Koswork сохраняются.

## Проверенные ориентиры

Официальные материалы просмотрены 27 ноября:

- [Codex: проекты, рабочие чаты, review и worktrees](https://developers.openai.com/blog/mastering-codex-remote-for-engineering).
- [Официальный обзор с навигацией Codex: закреплённые, проекты, недавние](https://learn.chatgpt.com/docs/features).
- [Claude Code Desktop: рабочие сессии и панели](https://code.claude.com/docs/en/desktop).

Сравнение опирается на документацию и доступные в ней представления интерфейса.
Не заявляется проверка всех вариантов UI, тарифов или экспериментальных раскладок.

| Область          | Обычный чат               | Кодовое пространство               | Решение Koscode                                                          |
| ---------------- | ------------------------- | ---------------------------------- | ------------------------------------------------------------------------ |
| Основная единица | Переписка                 | Сессия работы над проектом         | Проекты с вложенными сессиями                                            |
| Боковая панель   | Общая история и категории | Рабочие проекты и задачи           | Один список без дублей «Чаты / Активные задачи / Проекты»                |
| Контекст         | Текст разговора           | Репозиторий и выбранная ветка      | Настоящий repository/branch из существующих данных                       |
| Основная область | Лента сообщений           | Задание, код и результат изменений | В рабочем экране задание и изменения/проверки рядом                      |
| Продолжение      | Открыть беседу            | Вернуться к конкретной сессии      | Сохранённые задачи выбираются в панели и компактном переключателе        |
| Обратная связь   | Ответ модели              | Diff, результаты проверки, PR      | Существующие редактор, terminal/check evidence и подтверждения сохранены |

Это адаптация структуры и принципов навигации, а не перенос чужого брендинга,
ассетов или исходного кода. Реализован собственный компонент без новых пакетов.

## Что изменено

1. Общая `KoscodeNavigation` используется в кодовом режиме главной страницы
   и на `/code-agent`. Поиск фильтрует проекты/сессии, группы сворачиваются.
2. В кодовом чате сохранены меню сессий: закрепление, переименование, перенос,
   удаление и существующие права. Koscode/Work остаются в кодовом пространстве.
3. Создание проекта и новой сессии вызывает существующие функции. Обычные
   чаты и Studio не попадают в кодовую панель.
4. В рабочем экране слева проекты и сохранённые задачи; сверху — контекст
   проекта/ветки и компактный выбор сессии. Задание и результат разделены
   на две области с адаптивным переходом к одной колонке.
5. Статусы показываются только из server run state. Для ещё не загруженных
   проектов прямо указано, что их сессии не загружены. Выдуманных активных
   задач, терминальных команд, процентов, веток или изменений нет.
6. Панель меняет ширину, сворачивается, на телефоне открывается как drawer.
   Клавиатурный фокус, Escape поиска и reduced-motion поддержаны.
7. Переходы по новым ссылкам и выбор сессии сохраняют проверку несохранённых
   правок. Модель, разрешения, API, запуск проверок и создание PR не изменены.

Палитра чёрно-белая, иконки и типографика используют существующий стандарт.
Основной логотип не перерисовывался. Новые стили изолированы CSS Modules.

## Приёмка

- Проверки `koscode-navigation.spec.ts`, `code-agent.spec.ts` и
  `github-integration.spec.ts`: иерархия, поиск, рабочие ссылки, сохранённые
  задачи, dirty navigation, подтверждения, кодовые проверки и мобильная ширина.
- Отдельная проверка сохраняет обычную навигацию Kosmora.
- Визуальные снимки создаются в `qa/koscode-*.png` на локальных fixtures;
  показанные файлы/задачи являются демонстрационными данными.
- Изолированный прогон: `KOSMORA_E2E_PRODUCTION=1 pnpm --filter @cosmora/web exec playwright test --config playwright.koscode-design.config.ts`.
  Используются собственные loopback-порты 3338/3138, без доступа к VPS и платным моделям.

Из API-поставки OpenCode 5 (#701) ничего не перезаписывается: та ветка меняет
сервис Code, а этот проход ограничен интерфейсом и его проверками.

Итог локальной приёмки: **58/58 браузерных сценариев прошли на production-сборке**.
Проверки типов web (включая Office/Composer/Code E2E) и целевой ESLint прошли.
Полный CI итогового PR учитывается отдельно; сервер этой работой не обновлялся.
