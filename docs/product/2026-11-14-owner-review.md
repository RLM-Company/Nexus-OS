# Разбор демки Kosmora 14 ноября 2026

| Блок          | Сценарий приёмки                                                                                                                                                                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Профиль       | При регистрации и в профиле можно указать имя и род обращения. Для существующих аккаунтов обращение по умолчанию в мужском роде. Род речи ассистента настраивается отдельно. При наличии имени экран приветствует пользователя по имени.             |
| Ускорение     | Сравнить время до первого токена и до завершения одинаковых заданий, оценить качество. На Hy4 текущие оптимизации уменьшают подготовку запроса, но не меняют усилие модели.                                                                          |
| Проекты       | Проект объединяет отдельные чаты, общие файлы, инструкции и память проекта. Любой чат можно перенести, сохранив историю. Другие проекты не получают к ней доступ через память.                                                                       |
| Анализ файлов | ZIP и документы на тысячи страниц обрабатываются частями с очередью, отменой и отчётом о покрытии. Подробный режим делит работу автоматически и явно отмечает необработанные страницы и файлы.                                                       |
| Studio        | Реальные тесты подключённых провайдеров изображений, видео и звука. Music как отдельный раздел. Создание редактируемого PPTX по запросу модели. Инструменты открываются внутри общей оболочки.                                                       |
| Интеграции    | Каталог распространённых сервисов и подключение пользовательского HTTP API или MCP при наличии совместимого интерфейса. Проверить доступ, отзыв разрешений и журнал действий.                                                                        |
| Koswork       | Из исходных файлов получить готовый проверяемый результат. По ходу видны прогресс и материалы. Пользователь может изменить задачу, отменить запуск и возобновить работу. Агент работает с разрешёнными локальными файлами, браузером и интеграциями. |
| Koscode       | Боковая панель группирует сессии по проектам и показывает активные задачи. Из сессии доступны состояние работы, изменения и проверка результата.                                                                                                     |

Проекты Codex дают чатам собственные истории и общие рабочие файлы. ChatGPT Work использует файлы и подключённые инструменты для готового результата, показывает прогресс и поддерживает корректировку задачи. Claude Cowork дополнительно описывает параллельную работу и подключение локального окружения. Claude Code группирует активные и недавние сессии по проектам и предлагает фильтры по статусу и окружению.

- [ChatGPT Work](https://learn.chatgpt.com/docs/get-started-with-work)
- [Claude Cowork](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)
- [Боковая панель Claude Code](https://claude.com/blog/claude-code-desktop-redesign)

Сайты и игры ждут отдельной проверки по запросу владельца. Multi-Agent остаётся на последнюю очередь.
