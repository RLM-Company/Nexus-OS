# Интеграция блока 07

- `aedcc18f` добавляет экспорт ElevenLabs и явное подключение в `apps/api/src/server.ts`.
- `da162743` добавляет экспорт Google Cloud и создание адаптера видео в `apps/api/src/server.ts`.
- `0679b385` меняет действующий тематический контракт `packages/contracts/src/presentation-package.ts`. `packages/db/src/presentation-store.ts` и production-маршрут презентаций принимают то же необязательное поле, используя существующее JSON-хранение и историю.

- Изменений миграций, схем SQL, зависимостей и lockfile нет. Форматы jobs и версий расширены обратно совместимыми полями. При откате старый процесс не умеет показывать новые типы jobs и новые визуальные поля, а уже выданные файлы и версии остаются в хранилище.

Для включения в разрешённой тестовой среде установите `KOSMORA_MEDIA_PAID_ENABLED=true`. ElevenLabs требует `KOSMORA_MEDIA_ELEVENLABS_ENABLED=true` и `KOSMORA_MEDIA_ELEVENLABS_API_KEY`. Google Cloud требует `KOSMORA_MEDIA_GOOGLE_VIDEO_ENABLED=true`, `KOSMORA_MEDIA_GOOGLE_VIDEO_PROJECT` и ограниченный `KOSMORA_MEDIA_GOOGLE_VIDEO_ACCESS_TOKEN`. Токен короткоживущий и предоставляется через среду запуска. Перед живой проверкой администратор подтверждает доступ проекта к модели, квоту и способ обновления токена. Настройки OpenAI для изображений и речи остаются прежними. Для выключения отключите флаги нового провайдера, затем перевыпустите API по принятой процедуре. Удаление сохранённых артефактов для выключения не требуется.
