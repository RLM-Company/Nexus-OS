# Поставка 07 Gemini

[Draft PR #689](https://github.com/RLM-Company/Nexus-OS/pull/689) показывает точный проверяемый HEAD и результаты CI. База `3af92583ccc8ceb49f44c0b8633955f40feaf59f`.

## Возможности

Studio создаёт отдельные задания Music, SFX и Video через существующий runtime. В интерфейсе есть параметры, подтверждение, отмена, история, воспроизведение и скачивание. Генерация клипа для сохранённой версии сцены сохраняет прежние клипы. Раскадровка экспортируется отдельным JSON. Из обычного чата команды Studio возвращают ссылки на файл, а существующие команды изображений сохраняют рабочий путь в редактор.

В презентациях после обычного импорта разрешены версионируемые изображение, таблица и заметки выбранного слайда. Скачиваемый PPTX содержит редактируемые объекты OOXML. Правки одного слайда сохраняют исходные части остальных слайдов.

## Результаты проверок

23 проверки API и 8 проверок обновления базы прошли локально. На production-сборке в системном Chromium прошли все 14 целевых сценариев, включая чтение метаданных MP3/MP4, восстановление ответа и историю. Первый dev-прогон словил таймауты. В первом production-прогоне сценарий заметок выявил пересечение селектора с одноимённой настройкой поиска. Исправленный тест вошёл в полный повторный прогон. Скачанный в браузере PPTX открыт в LibreOffice Impress, приложен рендер. Проверка секретов и git diff прошли. Полный CI отслеживается по итоговому SHA в PR.

## Границы проверок

Транспорт провайдеров подменён только тестами. В доступной среде отсутствуют разрешённые учётные данные ElevenLabs, Google Cloud и OpenAI Media. Живую генерацию, тарификацию и ротацию облачного токена проверяет интегратор после явного допуска тестового аккаунта. Сборка сцен в итоговый ролик и правка по маске отсутствуют. Слайд «Текст» поддерживает одно изображение или таблицу. Генерация Work остаётся текстовой, визуальные данные добавляются в редакторе.
