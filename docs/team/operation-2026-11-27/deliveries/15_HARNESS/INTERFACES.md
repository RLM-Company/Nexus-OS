# Интерфейсы управления задачами

База `3af92583ccc8ceb49f44c0b8633955f40feaf59f`. Панель плана наблюдает точную пару `project/plan` из адреса. Публикуются только серверные IDs, версия, зависимости и состояние. Любой журнал замеров относится к подтверждённой паре work/attempt.

Work читает `GET /api/v1/projects/:projectId/work/:id/runtime`. Добавлено совместимое поле `version` исходной задачи. Панель сверяет ID и минимальную принёсшую его версию. Она показывает длительность только между соседними сохранёнными событиями с известной фазой. Действия остаются у `/control` и `/supplier-answer`. Уточнение сравнения обязательно, текст ответа передаётся вместе с версией задачи. После потери ответа принимается точное подтверждение из чтения той же задачи.

Koscode использует сохранённый интервал между элементами журнала выбранной задачи. Stars восстанавливает выбранный ID миссии по ссылке, сверяет версию миссии и связанного графа. Видео, звук и изображения используют фактические job ID и статус MediaService, а образец времени берётся из `created_at` и `updated_at` терминальной записи. У каждого режима остаются собственные допустимые команды и авторизация.
