# Сохранённые интерфейсы

Публичные HTTP-схемы и сигнатуры хранилища не изменены.

- `startAssistantMessage`: возвращает null для terminal run; вставка assistant
  и перевод запуска в running выполняются одной транзакцией.
- `appendAssistantDelta`: пишет только streaming assistant активного running run.
- `failRun`: сохраняет терминальную отметку даже до первого токена; поздняя ошибка
  не переписывает уже завершённый статус.
- `recoverInterruptedRuns`: сохраняет исходный запрос и частичный ответ, чинит
  последнюю осиротевшую запись. Ничего не отправляет провайдеру повторно.
- `GET /api/v1/chat-runs/:runId/events`: read-only observer; прежние события
  message.started/delta и run.failed/cancelled теперь восстанавливают частичный
  текст в правильном порядке. Исчезнувший запуск даёт terminal RUN_NOT_FOUND.
- `startChatStreamHeartbeat`: внутренний helper, возвращающий идемпотентную
  функцию очистки. SSE-комментарии не являются событием выполнения задачи.

Границы owner сохраняются; пути к секретам, содержимое личных чатов и провайдерские
ключи не нужны. Новый фоновый исполнитель или scheduler не создаётся.
