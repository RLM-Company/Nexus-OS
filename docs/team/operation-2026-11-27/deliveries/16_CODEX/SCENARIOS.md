# Проверенные сценарии

| Сценарий                                              | Проверенный результат                                                                     |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Claim → остановка до создания assistant → перезапуск  | Сохранены исходный вопрос и явная ошибка; бесконечной очереди нет                         |
| Старый failed-run без assistant                       | Последний такой запуск получает терминальную отметку; более новый запрос не перекрывается |
| Ошибка сохранения отметки при recovery                | Вся транзакция откатывается; повтор после устранения ошибки работает                      |
| Pending assistant при перезапуске                     | Сохранённый текст остаётся, статус становится failed                                      |
| Поздний текст после cancel/fail/complete              | Состояние и текст больше не меняются; повторный start запрещён                            |
| Переподключение после ошибки/отмены                   | Частичный текст приходит перед terminal event; нового модельного вызова нет               |
| Потерян ответ на POST, затем повтор после перезапуска | Возвращается тот же run ID; второй запуск не создаётся                                    |
| Два наблюдателя, один отключился                      | Одна генерация и одна запись usage; второй получает результат                             |
| Удаление чата в другом окне                           | Наблюдатель завершается с RUN_NOT_FOUND                                                   |
| Другой владелец запрашивает поток                     | 404 без чужого текста                                                                     |
| Тишина в потоке                                       | Keep-alive без фиктивного прогресса; таймер освобождается                                 |
| Остановка сервера при queued observer                 | Соединение закрывается; очередь остаётся сохранённой, модель не вызывается                |

Реализация проверок: `packages/db/test/general-chat-reliability.test.ts`,
`apps/api/test/general-chat-recovery.test.ts`, `apps/api/test/chat-stream-heartbeat.test.ts`.
Существующие API/coordinator, usage и project-тесты включены в прогон.
