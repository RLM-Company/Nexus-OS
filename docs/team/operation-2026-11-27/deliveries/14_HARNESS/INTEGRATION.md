# Интеграция анализа пакетов

Тематический SQL `0081_document_answer_batches.sql` и соответствующая запись журнала миграций вынесены отдельно. Номер 0081 и timestamp предварительные. Перед общим сведением интегратор проверяет соседние миграции. Переход с 0077 добавляет таблицу партий с каскадным удалением по попытке. Существующие задания, индексы и права сохраняются. Нет новых зависимостей и изменений app.ts/server.ts.

При откате старый runtime игнорирует реестр партий; история ответов и исходные файлы остаются. Таблицу следует сохранить, если требуется вернуть возможность продолжения после повторного обновления.

PR #691, #694 и #695 уже используют номер 0078. Для этой поставки проверен предварительный 0081 с более поздним timestamp. В общем кандидате объедините журнал ровно один раз в порядке применения всех соседних миграций.
