# Интеграция анализа пакетов

Тематический SQL `0078_document_answer_batches.sql` и соответствующая запись журнала миграций вынесены отдельно. Номер 0078 и timestamp предварительные. Перед общим сведением интегратор проверяет соседние миграции. Переход с 0077 добавляет таблицу партий с каскадным удалением по попытке. Существующие задания, индексы и права сохраняются. Нет новых зависимостей и изменений app.ts/server.ts.

При откате старый runtime игнорирует реестр партий; история ответов и исходные файлы остаются. Таблицу следует сохранить, если требуется вернуть возможность продолжения после повторного обновления.
