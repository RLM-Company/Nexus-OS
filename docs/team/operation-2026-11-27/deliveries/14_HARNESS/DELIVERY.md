# Большие документы · Harness 5

Production-путь «Файлы → подробный анализ» сохраняет партии по мере выполнения. Pause сохраняет готовые части, retry продолжает по точным сверенным источникам, ошибочные партии отображаются в покрытии и NDJSON. Синтез читает партии по порядку ограниченными страницами SQLite и объединяет группы, не загружая всё содержимое пакета в память.

ZIP/PDF/OCR, исходные ссылки, поисковая индексация, старые отчёты и ранее существовавшая привязка запроса повтора сохранены. Сценарий этой поставки использует фактические API, SQLite и синтетического поставщика модели. Живой платный вызов не выполнялся. [Команды и метрики](./SCENARIOS.md).
