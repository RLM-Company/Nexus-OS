# 11_OPENCODE — сценарии

## S1 — полный цикл разработки (реально решён локально)

Задача → immutable snapshot GitHub → точный unified diff → выбор изменений →
разрешённая проверка `node --test` в изолированном окружении → честный отказ →
исправление → повторная проверка → явное подтверждение → один Draft PR.
Воспроизведение: `apps/api/test/code-agent-workbench.acceptance.test.ts`,
реальный локальный git-репозиторий с функцией `add(a,b)` и её тестом.

## S2 — утечка непроверенного вывода модели (реальный дефект, исправлен)

Прерванный поток генерации сохраняет `output_checkpoint` с типом
`unvalidated_model_output` и сырым текстом ассистента. До исправления GET
`/api/v1/projects/:p/code-agent/:id` возвращал этот текст владельцу (воспроизведено
с токеном формы `sk-proj-...` в ответе). После исправления представление задачи
содержит только проверенное состояние, точный diff, journal и одноразовый токен
публикации. Воспроизведение: `code-agent.test.ts` test
"never exposes an unvalidated model output checkpoint through a run view".

## S3 — отказы и восстановление (сохранённая регрессия)

- Отмена во время потока: checkpoint сохраняется, публикация запрещена, повтор
  создания не вызывает повторную генерацию.
- Отмена во время проверки: поздний результат не перезаписывает состояние, GitHub
  не получает запись.
- Смена базы до записи: `GITHUB_BASE_CHANGED`, старый publication token аннулирован.
- Stale diff / stale review: точные hash и version, отказ без изменения состояния.
- Executor unavailable / ошибка проверки: честный `failed`/`unavailable`, повтор
  только после новой явной проверки; старый пройденный результат не публикуется.
- Потеря ответа публикации и повтор подтверждения: `reconcile` находит уже
  созданный PR, повторный `publish` не выполняет GitHub POST.
- Чужой проект/владелец: `404`; состояние нельзя прочитать или изменить.

## S4 — живая публикация (ожидает назначения)

Требуется выделенный тестовый репозиторий, `GH_TOKEN`, pinned `CODE_AGENT_TEST_IMAGE`
и рабочий OCI runtime. Готовый сценарий:
`apps/api/test/code-agent-live-github.acceptance.ts`. В текущем окружении нет
назначенного репозитория и Docker, поэтому живой шаг не выполнялся.
