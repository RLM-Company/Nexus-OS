## Операции в Studio

| Раздел      | Реальный путь и граница                                                                                                                                                                                                                                                                                                                                                                                                                |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Изображения | Генерация и правка через действующие endpoints провайдера. Графические параметры берутся из реестра. При правке сохранённый оригинал читается владельцем по ID и копируется в multipart байт в байт. PNG и JPEG до 1 МБ, можно добавить ещё один загруженный референс. Новый результат имеет отдельный ID. История показывает обе версии, сравнение и скачивание. Маски, точечная правка и сохранность конкретной области не заявлены. |
| Видео       | Сохранение сцен, плановая длительность, история, принятие конкретной версии и JSON-экспорт через действующий Studio. Правка сцены сохраняет старые версии и принятые соседние сцены. Настоящая видеогенерация, видеореференсы и замена клипа требуют поддерживаемого провайдера. JSON — раскадровка.                                                                                                                                   |
| Sound       | Озвучивание текста через существующий speech adapter. Studio передаёт голос, скорость и заявленный формат MP3/WAV/Opus, воспроизводит и скачивает подтверждённый файл. Range выдаёт запрошенные байты и проверяет доступ до чтения. Фикстурный PCM в тестах проверяет формат, HTTP и хранение. Проверка того, что реальный провайдер произносит присланный текст, остаётся живой.                                                      |
| SFX и Music | Обозначены отдельно. API отдаёт `ready=false`, интерфейс не запускает генерацию и не выдаёт аудио-заглушку. Нужны отдельные поддерживаемые маршруты провайдера.                                                                                                                                                                                                                                                                        |
| Презентации | Сохранён текущий путь Work → редактор → PPTX. При повторном экспорте проверяются изменённый слайд и байтовая сохранность XML других слайдов и заметок.                                                                                                                                                                                                                                                                                 |

Медиа и раскадровка принадлежат аккаунту. Они не назначаются проекту по входному параметру, поэтому изменения не расширяют доступ участников проектов. Явное удаление исходного изображения лишает возможности повторно использовать его в новых правках. Платные jobs сохраняют существующий механизм отмены и восстановления. Повтор того же запроса не создаёт новую задачу. При прерывании процесса незавершённый платный запуск помечается как прерванный и автоматически не повторяется. У раскадровки единый снимок на владельца, максимум 12 сцен и 12 версий на сцену. Снимок входит в экспорт и удаление аккаунта.

## Проверки

- Production API с внедрённым fetch — `pnpm --filter @cosmora/api exec vitest run test/studio-candidate.test.ts test/media-api.test.ts test/media-routes.test.ts test/media-acceptance-integration.test.ts test/media-durable-lifecycle.test.ts`. Два настоящих по формату PNG с разными пикселями из фикстуры. Проверены multipart, байты, история, ложный или чужой источник, повтор после рестарта, отмена и поздний ответ, Range и отсутствие второго сетевого запроса при URL-only/redirect. Текстовая раскадровка проходит реальные API и дисковое хранилище с проверкой CAS, экспорта и удаления.
- Браузер — `KOSMORA_E2E_PRODUCTION=1 pnpm --filter @cosmora/web exec playwright test e2e/studio-storyboard.spec.ts e2e/media-job-recovery.spec.ts e2e/media-budget-history.spec.ts e2e/presentation-work.spec.ts e2e/owner-ui-media.spec.ts e2e/capability-workspaces.spec.ts e2e/studio-music.spec.ts`. Storyboard и PPTX проходят штатные маршруты. Media UI использует контролируемые ответы, модель Work для презентаций — фикстура.
- Схема — `pnpm --filter @cosmora/db exec vitest run test/project-intake-upgrade.test.ts`. Журнал миграций не менялся. Раскадровка сохраняет только компактный JSON в каталоге действующего файлового хранилища, бинарные файлы остаются в MediaFileStore.
- Live — платные вызовы изображения, редактирования и речи не выполнялись. Живые режимы и параметры проверяются при подтверждённом доступе к провайдеру. Для видео, SFX и Music в текущем реестре маршрутов нет. Включение Studio не требует смены провайдера, конфигурации или миграции.

Точная версия и проверки общего кандидата публикуются в #688. Слияние и деплой выполняются на следующих этапах после приёмки.
