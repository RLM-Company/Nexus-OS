## Целевой сценарий (по поручению)

1. Проект = папка: несколько чатов, общие файлы, инструкции.
2. У каждого чата своя история; чат открывается по ссылке.
3. Меню чата: «В проект», «Переместить в другой проект», «Вернуть в общий список».
   Перенос сохраняет историю, вложения и ссылку на чат.
4. Новый чат проекта использует важные договорённости/материалы других чатов
   проекта **с указанием источника**.
5. Проверки: перенос, повтор запроса, перезагрузка, изоляция памяти между
   проектами и конфиденциальными чатами.
