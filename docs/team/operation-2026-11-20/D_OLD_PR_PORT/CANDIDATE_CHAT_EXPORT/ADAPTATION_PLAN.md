## Что меняется

1. `apps/web/src/app/chat-export.ts`
   - `ChatExportFormat` расширяется до `"markdown" | "json" | "text" | "html"`.
   - Добавляется `escapeHtml()` — отдельный от Markdown-`literal()`, чтобы
     HTML-экспорт не подменял код и не интерпретировал разметку модели.
   - `.txt`: плоский текст, дословное содержимое сообщений, даты, статусы и
     только названия/типы вложений.
   - `.html`: `<pre>` с экранированным содержимым, заголовок, даты, статусы,
     список вложений. Это читаемая копия переписки, не полноценный рендер.
   - Имя файла получает расширение `txt`/`html`; существующая фильтрация
     system_event и режим `attachments_mode: metadata_only` не меняются.
2. `apps/web/src/app/chat-export-controls.tsx` — два новых `<option>` в
   уже существующем `<select>`.
3. `apps/web/src/app/chat-item-menu.tsx` — два пункта в уже существующем меню,
   с уже используемой иконкой `download`.
4. `apps/web/src/app/chat-export.test.ts` — два теста: текстовый формат
   и экранирование HTML.

- Содержимое вложений, изображения и system_event не попадают ни в один формат

- Отмена и асинхронность ZIP-пути не затрагиваются.
