# Очередь кандидатов после одобренного переноса

Одобрен и подготовлен один пункт — экспорт `.txt`/`.html`
([патч](CANDIDATE_CHAT_EXPORT/0001-chat-export-text-html.patch)).
Дальнейшие пункты **не одобрены**, поэтому работа по ним не продолжалась:
[instruction AGENTS](../../../../AGENTS.md) требует согласовывать новый объём
до реализации, а в задаче сказано брать следующий пункт, пока остаются
согласованные кандидаты.

| #   | Кандидат                                                      | Источник                         | Почему не взят сейчас                                                       | Что нужно от владельца                                       |
| --- | ------------------------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 1   | Индикатор бюджета контекста                                   | PR330 block 3; prototип F173     | Нет найденной реализации в `apps/web/src`; потребует UI                     | Точечный запрос на компоновку composer                       |
| 2   | Глобальный Cmd/Ctrl+K                                         | PR380 F127                       | Поиск в `apps` не нашёл; это новая навигация                                | Решение по границам поиска и UI                              |
| 3   | Welcome/starter cards                                         | PR330 block 5                    | Изменение начального экрана чата                                            | Явный точечный запрос по `UI_RULES.md`                       |
| 4   | Telegram-шлюз                                                 | PR380 F076                       | Внешний сервис и секреты                                                    | Разрешение на интеграцию и учётные данные                    |
| 5   | Новые APEX-адаптеры (F173/F176/F178/F180/F199/F204/F211/F212) | `packages/core/src/apex/stage*/` | Есть чистые прототипы, но каждый требует входных границ и негативных тестов | Выбор одного ID и подтверждение, что это продуктовая функция |

Порядок не означает приоритет: это список незакрытых решений, а не план
реализации. После ответа владельца по одному из пунктов взять его следующим
и повторить цикл «патч + проверка совместимости».
