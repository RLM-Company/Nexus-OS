# Шаблон сообщения об ошибке (скопируйте целиком)

```
ID: [короткий: дата-инициалы-порядок]
Дата/время (Москва):
Версия кода: 51ce52a9  [или другая, если в интерфейсе указана иная]
Платформа: [Web / Windows-клиент / другое]
Шаг сценария: [1–8 из сценария 5–7 минут]
Действие: [что именно сделали, дословно]
Ожидалось: [например: 18 000 ₽ без доставки и ссылка на orders.csv:2]
Фактически: [что получили, дословно]
Данные/вложения: [brief.txt / orders.csv / notes.md / другое]
Повторяется: [да, каждый раз / один раз / не проверяли]
Ранее работало: [да/нет/не знаю]
Скриншот или лог: [приложить, если есть]
Контакт для уточнения: [по желанию]
Разрешение на публикацию в закрытом канале: [да/нет]
```

## Правила заполнения

- Одно сообщение — одно расхождение. Если их несколько, сделайте несколько
  копий шаблона.
- «Фактически» пишите дословно, без исправлений и без «по идее должно быть…».
- Указывайте шаг сценария: это позволяет быстро привязать отчёт к
  [схеме разбора](FEEDBACK_TRIAGE.md).
- Если точную версию узнать нельзя, напишите «неизвестна» — не гадайте.
- **Вырезайте** пароли, токены, ключи, реальные клиентские данные и чужие файлы.
  Для демонстрации достаточно вымышленных строк из демо-набора.
- Если вы нашли расхождение в ответе модели, приложите сам вопрос; без него
  воспроизведение невозможно.

## Что НЕ считается ошибкой

- Отказ отправить письмо/платёж/управлять компьютером — ожидаемая граница.
- Ответ без «красивого» форматирования, если цифры и источники верны.
- Расхождение с другим продуктом без сопоставимого сценария.
- Замечание «медленно» без замеров времени; приложите фактическое время,
  если оно есть.
