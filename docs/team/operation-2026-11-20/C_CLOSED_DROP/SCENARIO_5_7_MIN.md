# Сценарий первой группы: 5–7 минут

**Версия кода:** `51ce52a9`. **Данные:** [DEMO_DATA](DEMO_DATA/README.md).
**Режим:** обычный чат Kosmora + проект. Модель в локальной репетиции — mock;
у кандидата может быть живой провайдер, поэтому оценивается не «красивость»
ответа, а проверяемые числа, источники и честные отказы.

Ведущий молча заполняет [схему разбора](FEEDBACK_TRIAGE.md) по ходу, а не по
памяти. Ошибку кандидат отправляет через [шаблон](ERROR_REPORT_TEMPLATE.md).

Итого 6,5 минуты. Если шаг 1 уже пройден у кандидата, время передаётся шагу 3;
общая длительность сохраняется в пределах 5–7 минут.

## Что ведущий не делает

- Не просит «сравнить с ChatGPT/Claude» и не обещает превосходство без
  сопоставимой проверки.
- Не показывает граф знаний как «параметры модели» и mock-ответ как живую модель.
- Не просит реальные пароли, ключи, клиентские данные или управление ПК.
- Не закрывает замечание без минимального воспроизведения: сначала
  [схема разбора](FEEDBACK_TRIAGE.md), затем передача владельцу.

блокеров — см. [REHEARSAL_LOG.md](REHEARSAL_LOG.md). Живая репетиция с
кандидатами не проводилась; это отдельный незакрытый шаг.
