## Проходы (по поручению)

1. **Приём задания.** Связать цель, материалы и зависимости; сохранить входные
   данные и повторные запросы; на одном наборе данных построить зависимый план
   и получить проверяемый результат. → _срез A: `work-admission-context`_
2. **Управление.** Очередь, пауза, явное продолжение, отмена, повтор после
   сбоя; restart без повтора закрытых шагов. → _срез B_
3. **Сдача.** Проверка содержимого, источники, публикация, полный/частичный ZIP,
   понятные статусы. → _срез C: `results.zip?node_ids=` + статус сдачи_
4. **Расписание.** Повторные даты, один экземпляр на срабатывание, отмена и
   явный старт подготовленной задачи; отдельные задания для restart и
   повторной доставки. → _срез D: связать scheduled dispatch с admission-срезом_
5. **Второй сценарий** с другой структурой входов; один пользовательский
   сценарий с реальной моделью на согласованной среде; передача состояния и
   событий для плана/таймеров чата. → _срез E_
