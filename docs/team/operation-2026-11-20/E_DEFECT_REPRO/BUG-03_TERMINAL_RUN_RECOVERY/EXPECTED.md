# Ожидаемое поведение — BUG-03

- Для одного run ID последнее авторитетное терминальное событие имеет
  приоритет над устаревшей историей.
- Завершённый запуск не воскресает из устаревшей истории: нет повторного
  открытия SSE и цикла «queued → terminal → refresh».
- Один наблюдатель на запуск, а не 12/15/17.
- Кнопка/состояние не мигает между `disabled` и активным.
- Новый run ID восстанавливается обычным путём.
- Текст, вложения и черновик переживают перезагрузку; повторной отправки нет.
- Причина исходной отмены остаётся неизвестной и не выдумывается.
