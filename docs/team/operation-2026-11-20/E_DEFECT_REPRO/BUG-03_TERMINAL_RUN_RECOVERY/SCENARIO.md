# BUG-03: завершённый запуск «оживает» после перезагрузки

**Владелец:** 01_CODEX (чат и восстановление запусков).
**Оригинал:** [TERMINAL_RUN_RECOVERY_2026_11_13_RU.md](../../../operation-2026-11-10/deliveries/02_DEVELOPER/TERMINAL_RUN_RECOVERY_2026_11_13_RU.md).

## Минимальные данные

[input.json](input.json): один run ID с повторяющимся `run.cancelled`,
история только с пользовательским сообщением, повторное открытие SSE.

## Шаги

1. Создать терминальный запуск и записать его последнее событие.
2. Перезагрузить страницу; восстановить состояние из истории.
3. Проверить, что восстановленное состояние — терминальное.
4. Открыть SSE и обновить страницу ещё раз.
5. Убедиться, что нет цикла queued → terminal → refresh → queued.
6. Повторить для statuses `completed` и `failed`.
7. Отдельно проверить новый run ID: он должен восстанавливаться нормально.
