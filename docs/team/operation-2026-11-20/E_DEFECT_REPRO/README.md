1. Есть минимальные синтетические входные данные.
2. Есть сценарий с явным ожидаемым поведением.
3. Есть доказательство baseline-отказа и проверка после исправления
   (или честно отмечено, что исправления ещё нет).
4. Дефект не требует живого платного провайдера или управления ПК владельца.
