# Ожидаемое поведение — BUG-01

- Кнопка «Вернуть запрос в редактор» показывается только для последнего
  терминального запуска с подтверждённым статусом и историей вида
  «только пользовательское сообщение».
- Восстановление выполняется **только** в пустой редактор: без нового текста
  и без новых вложений.
- Если пользователь начал новый запрос (текст или файл), старый запрос не
  затирается: новый текст и `pending.txt` остаются на месте.
- Восстановленный текст в точности равен `source_text`, вложения — ровно
  `original.txt`.
- Восстановление не отправляет повторный запрос модели и не меняет историю.
- После перезагрузки страницы черновик сохраняется.
- Дополнительные проверки показываются и на live-пути (не только в тесте).
