# Очередь Codex

## O-001 — интегрирован через PR505

Приёмка результата Work только при сохранённом полном современном наборе
опубликованных файлов: версии, байты, draft и отсутствие лишних/утраченных файлов.
Общий кандидат принят после полного CI; живая приёмка отдельно.

## Следующие проверки очереди

- Восстановление после потерянного ACK принятия: проверить поведение реального
  клиента перед изменением контракта; не дублировать событие принятия.
- Сохранение/восстановление проверенного Office-результата через Drive: проверить
  фактические entrypoints и недостающие связи, не создавать второй формат bundle.
- Выпуск: точный комплект API/web/DB/Windows и актуализация live runbook.

## Отложенное

VPS и owner-PC live acceptance не выполняются без снятия отложенного статуса.
Внешние модули принимаются по поставкам и результатам, а не по словам о запуске.

## O-002 — интегрирован через PR506

Drive fallback не подменяет утраченные современные версии legacy-файлами.
Четыре регрессии RED→GREEN, snapshot suite26/26 и общий CI прошли.

## Входящие поставки

PR504Media не включён в первую волну: отдельный review capabilities,
idempotency/reload/owner isolation перед включением. Не отправлять комментарии
внешним исполнителям и не менять их ветки без поручения владельца.
