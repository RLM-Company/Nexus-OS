# O-001: проверка результата перед приёмкой

## 2026-11-13 — безопасная смена документа Office

Koswork переключает документ и сбрасывает его план, страницы и результат
только после успешной проверки нового файла. При отказе или отмене остаётся
предыдущий снимок. Браузерная регрессия открывает DOCX по ссылке из Drive,
проверяет сохранение плана после ошибки разбора и сброс плана после загрузки PPTX.

## До / после

Раньше acceptResult проверял completed/done и версию задачи, но современный
опубликованный набор файлов повторно не проверял. Теперь до первой отметки
в той же транзакции проверяются непустой draft, уникальные имена, полный состав
опубликованных файлов и версий, byte-verified readback и совпадение с draft.
Повреждение, пропажа/лишний файл, чужой project или неопубликованная версия
дают ARTIFACT_INTEGRITY_MISMATCH (HTTP409) без изменения состояния и истории.
Повторное чтение уже принятого результата сохраняет существующую отметку.
Исторические pre-checkpoint записи сохраняют прежний путь; это не новая аттестация
их файлов. Приёмка владельцем по-прежнему не доказывает правильность содержимого.

## 2026-11-13 — использование исследования в проектном чате

Обновлён заголовок выбора источников проекта, чтобы в нём было видно исследования.

## 2026-11-13 — повтор восстановления Drive

После потери ответа вкладка хранит только ID операции для конкретной копии.
При повторном открытии предпросмотра интерфейс получает новый токен и после
явного подтверждения отправляет прежний ID. Сервер возвращает уже созданные
чаты и файлы из журнала. Успешный ответ очищает ID; на загрузке страницы
восстановление не запускается. При недоступном хранилище вкладки повтор с тем
же ID работает до перезагрузки. Следующая приёмка — подключённый Google Drive
на рабочем окружении.

## 2026-11-13 — защита текущего плана Office

Koswork просит подтверждение перед заменой текущего плана отличающимся
сохранённым черновиком. При отказе оба плана сохраняются. Пустой редактор
восстанавливает черновик сразу. Проверка актуальности черновика выполняется
до подтверждения внутри существующей блокировки между вкладками.

## 2026-11-13 — восстановление голосовой фразы

Распознанная и явно отправленная фраза попадает в обычный черновик до
запроса. После подтверждения он очищается по действующим правилам.
Если вкладку перезагрузить в ожидании ответа, фразу можно отправить тем же
запросом без дубля. Черновик пользователя, появившийся до отправки фразы,
сохраняется. Браузерный тест использует имитацию распознавания речи.

## 2026-11-13 — независимый повтор запросов внутри чата

Запросы без подтверждения сохраняются по отпечатку содержимого и области
чата. Успешная отправка другого сообщения очищает только его запись. После
перезагрузки повтор исходного запроса использует прежний идентификатор.
Хранилище вкладки по-прежнему ограничено 16 записями и хранит отпечатки,
а не текст запроса. Проверка использует локальный API и тестовую модель.

## 2026-11-13 — повтор создания задачи Manager

После явного запуска вкладка сохраняет исходные параметры задачи в рамках
её проекта. При перезагрузке форма восстанавливает цель, роль, проверку и
исходный бюджет. Повтор запускается вручную и использует тот же идентификатор.
Успешное подтверждение удаляет временную запись. При недоступном хранилище
вкладки остаётся прежний повтор до закрытия панели.
