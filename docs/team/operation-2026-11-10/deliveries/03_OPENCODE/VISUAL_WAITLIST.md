# VISUAL_WAITLIST — 03_OPENCODE

Предложения по видимым элементам (не реализуются в этой петле без решения владельца;
компоновка/стили не менялись).

1. **Кнопка «Повторить» для прерванных загрузок в Центре загрузок** (`downloads.html/js`).
   Контекст: прерванная загрузка честно помечается interrupted и «повторная загрузка
   не запускается автоматически» (main.cjs, will-download done-handler), но и ручного
   рестарта из истории сейчас нет — пользователь заново идёт в интерфейс.
   Предложение: кнопка «Повторить» у записи interrupted открывает повторный запрос
   того же origin-маршрута владеющей вкладкой (по-прежнему без автовыполнения и
   гарантий серверной стороны; сервер должен снова предложить тот же ресурс).
   Затрагивает окно загрузок (сфера 03_OPENCODE), но это новая видимая кнопка —
   требует явного одобрения владельца и следования правилам окна загрузок.
