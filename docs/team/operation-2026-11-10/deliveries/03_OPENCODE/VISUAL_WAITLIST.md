# VISUAL_WAITLIST — 03_OPENCODE

Предложения по видимым элементам (не реализуются в этой петле без решения владельца;
компоновка/стили не менялись).

1. **Кнопка «Повторить» для прерванных загрузок в Центре загрузок** (`downloads.html/js`).
   Статус: **одобрено владельцем 2026-11-11 и реализовано** (срез в DELIVERY).
   Честные границы реализации: повтор возможен только пока приложение помнит
   исходный запрос в памяти сессии (URL никогда не сохраняется — контракт окна
   «Ссылки скачивания не сохраняются» соблюдён); после рестарта запись остаётся
   «Прервано» без кнопки; повторный запрос снова проходит полный
   will-download policy-gate, без автовыполнения и гарантий серверной стороны.
