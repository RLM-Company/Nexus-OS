## Исправления при сведении

- Общие точки регистрации объединены без замены identity владельца данных.
- В Work DAG закрыто изменение плана участником с ролью viewer. Создание и импорт
  редактором используют владельца общего проекта; действующий actor сохраняется.
  Регрессионный тест проверяет чтение viewer, запрет записи, создание editor и revoke.
- Сохранены и иерархия Stars, и обработка устаревших состояний задач.
- В Koscode сохранён интервал событий задачи из #698. Проверки навигации обновлены
  под новые доступные имена; проверка ссылки проекта ограничена конкретным project id,
  чтобы другие проекты в общей фикстуре не создавали strict-mode ошибку.
- Office CSV добавлен в зависимости кеша сборки API.
- Общий manifest приведён к фактическим поставкам, без объявления живой приёмки.

## Не смешивать уровни доказательств

Целевые локальные проверки выполнены после последовательного включения поставок.
Общая проверка типов всех пакетов прошла. Полный CI обязателен для точного финального
SHA кандидата. Итог CI фиксируется в PR; этот документ не объявляет его заранее.

VPS не обновлялся и не проверялся в рамках этого сведения. Настоящий провайдер,
Windows владельца, первый пользовательский набор и реальные внешние действия
не считаются пройденными по результату mock-тестов. Автоматизация предоставляет
серверный tick API; наличие кода не означает, что оператор подключил периодический
такт на конкретном развёртывании.
