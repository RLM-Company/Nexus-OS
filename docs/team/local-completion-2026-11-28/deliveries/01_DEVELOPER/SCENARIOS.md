# Приёмочные сценарии

## API и фикстуры

```sh
pnpm --filter @cosmora/api exec vitest run --maxWorkers=2 test/research-workflow.test.ts test/research-report-export.test.ts test/research-receipts-user-run.test.ts test/research-synthesis.test.ts test/artifact-context-research.test.ts test/web-search.test.ts test/kosmora-actions.test.ts test/kosmora-actions-integration.test.ts
pnpm --filter @cosmora/core exec vitest run --maxWorkers=2 research-
```

HTTP Research и SQLite работают на настоящих обработчиках. Ответы SearxNG, модель и транспорт публичных страниц заменены синтетическими данными. Первый отчёт сохраняет «50 рублей» и «5000 рублей» в разделе расхождений. Зеркало связано с `S1` по совпавшему SHA-256 и отсутствует в модельном контексте. Те же URL, выдержки и хеши можно проверить в сохранённом результате и экспорте. После перезапуска хранилища исключение источника с 5000 рублей применяется к уточнённому запросу. Отчёт с 50 рублями ссылается на исходный. Повтор запроса возвращает тот же ID, подмена родителя даёт 409, чужой владелец получает 404. Отдельный тест отменяет чтение и возвращает поздний ответ транспорта. Состояние остаётся `cancelled`.

## Браузер

```sh
pnpm exec playwright --version
KOSMORA_E2E_PRODUCTION=1 pnpm --filter @cosmora/web exec playwright test --workers=1 e2e/research-canvas.spec.ts e2e/kosmora-chat-actions.spec.ts e2e/artifact-context.spec.ts e2e/web-search.spec.ts
```

Фикстуры браузера оставляют реальными Next, API и SQLite. В Research запустите «Какой код указан в архиве лунной станции?», отметьте `S1` как первичный источник с основанием, запустите уточнение «Какой код архива лунной станции указан в реестре?». Перезагрузите страницу и откройте исходный отчёт. Посмотрите перенос снимка в материалы проекта и чтение `SELENE-047` в ответе проекта.

В обычном чате отправьте «B5 код демо-архива» и выберите «Искать в интернете» под сообщением. Фикстурная модель возвращает «Код архива — B5-047.», ссылку «Демо-архив» формирует сервер. После перезагрузки ссылка доступна по тому же адресу. Запросы «B5 пустой поиск» и «B5 сбой поиска» показывают отдельные состояния и возвращают исходный ввод в редактор.

## Живой прогон

В среде с подключённым SearxNG проверьте `GET /api/v1/web-search/status`, затем в чате запросите документацию RFC 9110 и явно выберите поиск. Проверьте, что сохранённые ссылки ведут на ожидаемые публичные страницы. В Research выполните поиск по тому же вопросу с разрешением `context.web.read`. Запишите URL, статус чтения, дату и SHA-256. Модельный синтез включайте в согласованном тестовом окружении с учётом расходов.
