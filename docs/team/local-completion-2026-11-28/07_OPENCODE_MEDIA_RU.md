# OpenCode 6 — настоящие медиа и презентации

Прочитай `00_COMMON_RU.md` в ветке `team/local-completion-20261128`. Ветка: `completion/media-presentations-20261128`. ID: `07_OPENCODE`. Прими бывшую область Gemini, не рассчитывая на его продолжение.

Есть MediaService, jobs/assets, чат-команды, изображения, видео, ElevenLabs Sound/Music и редактируемые PPTX. В #689 транспорт провайдеров проверяли подменами. Сборка сцен в видео и правка по маске отсутствуют. Визуальные данные презентаций добавляются редактором; генерацию полноценного наполнения ещё нужно довести.

## Последовательная очередь

1. Пройди существующие генерации на настоящих поддержанных провайдерах. Сопоставь официальные API, модели и реальные возможности; не отправляй неподдержанные параметры/референсы.
2. Изображения: создание в чате/Studio, reference editing и маска, сохранённые параметры, проверка и скачивание файла. Повреждённый или чужой asset не принимается.
3. Видео: сцены, отдельные jobs, сборка в итоговый ролик с согласованными длительностями/форматами, preview, экспорт, отмена и восстановление. Внешние кодеки/бинарники закрепи по версии/лицензии.
4. Music/Sound: параметры, генерация, прослушивание и экспорт настоящего аудио. Voice playback/TTS — твой transport; голосовая логика и встречи принадлежат Harness 3.
5. Презентации: по запросу модель создаёт содержательную колоду с поддержанными визуальными объектами и источниками; файл открывается и редактируется в офисном приложении. Правка слайда сохраняет остальные части.
6. Общие jobs должны честно показывать ожидание/ошибку/отмену, переживать reload и не повторять платную операцию при неизвестном исходе.

Зона: media service/adapters/routes, media UI и presentations. Не меняй provider routing текста, Stars, общий sidebar. Согласованные тесты с настоящим провайдером — отдельные явные задания; отсутствие медиа-ключа не закрывай фикстурой. Секреты не публикуй, не делай автопополнения и фоновые повторы генераций.

## Приёмка

Настоящий файл изображения и его адресная правка, ролик из нескольких сцен, открываемое аудио, презентация с реальными редактируемыми объектами. Независимая проверка формата, размера, воспроизводимости, источника и результата после reload. Затем исправляй найденное, продолжая свою очередь. Поставка — код, PR/SHA, synthetic/live раздельно и список доступных функций по каждому провайдеру.
