# OpenCode 1 — самостоятельная автоматизация

Прочитай `00_COMMON_RU.md` в ветке `team/local-completion-20261128`. Ты владелец автоматизации по времени и событиям. Ветка: `completion/automation-20261128`. ID: `02_OPENCODE`.

Сейчас есть AutomationStore/Runner, workflows, event inbox и ручной `/api/v1/automation/tick`. Поиск вызовов не выявил самостоятельного периодического такта сервера. Устрани этот разрыв, используя существующий runtime.

## Очередь полноценной функции

1. Изучи automation-runner/routes, scheduled-dispatch и lifecycle сервера. Не создавай конкурирующие scheduler и очереди.
2. Подключи управляемый серверный цикл: due time → сохранённый запуск → WorkDAG → результат. Цикл должен останавливаться при shutdown и не удваиваться после restart.
3. Реализуй lease/claim и восстановление при двух экземплярах исполнителя. Повтор события/тика не создаёт второе действие. Известный завершённый шаг не выполняется заново.
4. Подключи подтверждения, отмену, паузу, изменение расписания и версии процедуры. Учти часовой пояс, однократные и повторяемые расписания, пропущенное время после сна/выключения.
5. Доведи события коннекторов через общий inbox; реальные service transports принадлежат OpenCode 2. Ошибки и неизвестный исход внешней записи сохраняются, слепого повтора нет.
6. Пользователь создаёт, включает, видит ближайший запуск, историю, результат и причину остановки. UI — только в настройках автоматизации/процедурах.

Зона: automation/workflow/scheduled-dispatch, соответствующие stores и UI. Stars потребляет этот механизм; второй scheduler для Stars не пиши. Публичные API очереди/webhooks принадлежат Codex, OAuth коннекторов — OC2. Общий server hook выдели отдельным integration commit.

## Приёмка

Локально создай процедуру, запусти её по времени без ручного tick, получи скачиваемый файл. Повтори событие, перезапусти процесс на середине, запусти два workers, отзови разрешение и отмени следующую операцию. Докажи отсутствие дублей. Внешние сообщения тестируй только на назначенном тестовом сервисе.

Веди петлю до подключённой функции с проверяемым результатом. Не заканчивай на новом timer helper или отчёте. Поставка — PR/SHA и документы по общим правилам.
