# DeepSeek Harness 2 — память, Skills и большие файлы

Прочитай `00_COMMON_RU.md` в ветке `team/local-completion-20261128`. Ветка: `completion/memory-skills-files-20261128`. ID: `09_HARNESS`.

Ты владеешь тремя связанными направлениями, выполняемыми последовательно: память → Skills → анализ больших файлов. Их основы уже есть; не создавай новый «единый engine» вместо действующих stores.

## A — долговременная работа

Продолжение длинного проекта после сжатия и restart; сохранение ограничений, решений, источников и версий. Доведи исправление факта, конфликт воспоминаний и удаление, включая производные summary/индекс/кеш. Личная, чатовая, проектная и командная память не смешиваются. Новый чат получает только разрешённые релевантные сведения с объяснимым источником. Не обещай абсолютную безошибочную память.

## B — работающие Skills

Версии навыков, выбор, применение в настоящем runtime, конфликт инструкций, отключение, rollback, сохранение пользовательского стиля. Проверь на новых заданиях, что включённый навык меняет результат по явному критерию. Принятие правила не выдавай за обучение весов модели. Расширяй законченные профессиональные сценарии после качества первой группы, а не ради числа названий.

## C — анализ файлов

ZIP и вложенные документы, сканы/OCR, смешанные большие пакеты: партии, продолжение, адресные ссылки на страницы, видимое покрытие, ошибки и пропуски. Доведи перераспределение обработки на поддержанные исполнители и финальный синтез без загрузки всего корпуса в один prompt. Файл после изменения не может использовать старый checkpoint как актуальный. Независимо проверь выводы настоящей модели, а не только счётчики обработки.

Зона: context-memory, semantic-memory, owner/chat Skills, document library/answer service, соответствующие core/db и UI. Drive OAuth/transport — OC2; совместные роли и идентичность не переписывай. Фильтрация owner/revoke/exclusions обязательна до извлечения данных, а не только после генерации.

## Приёмка

Длинный проект с решениями, конфликтом, исправлением и удалённым источником → сжатие/restart → новый вопрос. Затем тот же материал с включением/отключением Skill. Затем новый смешанный пакет файлов с проверяемыми контрольными фактами, отменой, продолжением и полным отчётом покрытия. Проверь двух владельцев и исключения.

Веди непрерывную петлю внутри A→B→C. Сдай PR/SHA, исходные контрольные задания, реальные ответы/артефакты и честные показатели качества; чувствительные данные используй только с назначением.
