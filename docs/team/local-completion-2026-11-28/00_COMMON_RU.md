## Непрерывная рабочая петля

1. Сопоставь задание с действующим кодом и отчётами прошлой поставки. Начни с разрыва, который мешает получить пользовательский результат.
2. Реализуй полный путь: интерфейс/клиент → API → исполнитель → состояние → проверенный результат. Подключение к действующему приложению обязательно.
3. Прогони нормальный сценарий, ошибку, отмену, перезапуск, повтор запроса и отказ чужому владельцу. Исправь подтверждённые дефекты.
4. Зафиксируй полезный срез коммитом и обнови checkpoint. Затем бери следующий незакрытый сценарий своей зоны, не ожидая отдельного поручения на каждый файл.
5. Заканчивай при выполнении критериев своего блока. Если зависимость недоступна, документируй её и продолжай независимые части; не создавай бесконечный цикл холостых тестов или сетевых повторов.

Не начинай с переписывания систем с нуля. Уже есть WorkDAG, guarded tools, membership, подтверждения, durable runs, media jobs, память и коннекторы. Архивные прототипы не являются готовой заменой. Перед новой существенной зависимостью проверь официальный источник, лицензию и совместимость; закрепи версию. Не выдавай обещания автора библиотеки за результат Kosmora.
