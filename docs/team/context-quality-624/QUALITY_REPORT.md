# Качество сформированного контекста: before/after

Зона заканчивается на сформированном контексте для модели: прогон не вызывает
модель, сеть, БД или внешние сервисы. Набор, метрики и правка детерминированы.

## Набор

`scripts/context-quality/fixtures/context-set.json` — 5 сценариев на одном наборе:

1. `continue-after-compaction` — продолжение после сжатия (цель + активный шаг);
2. `new-chat-in-project` — новый чат в проекте (проектные решения + цепочка сообщений);
3. `exact-quote` — поиск точной цитаты рядом с похожим, но другим лимитом;
4. `latest-revision` — две противоречащие ревизии одного решения (v1 vs v4);
5. `deleted-material` — удалённый черновик и сохранённый факт.

В каждом сценарии есть материалы владельца B (`owner: owner-B`) — похожий
проект другого владельца. Обязательные факты, ожидаемые и запрещённые ссылки
зафиксированы в фикстуре.

## Воспроизведение

```
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --experimental-strip-types \
  --import ./scripts/context-quality/ts-resolve-hook.mjs \
  scripts/context-quality/run.mjs baseline
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --experimental-strip-types \
  --import ./scripts/context-quality/ts-resolve-hook.mjs \
  scripts/context-quality/run.mjs optimized
```

`baseline` — текущий путь: дедупликация и ранг без владельца, версии и удаления.
`optimized` — `selectContextScope()` из `packages/core/src/context-evidence-selection.ts`.

Главное: увеличение объёма работы отсутствует, рост не наблюдается.

## Что исправлено

- **Дедупликация**: компактировка внутри группы сохранялась, но перед ней теперь отсекаются
  чужие владельцы, удалённые источники и старые ревизии того же предмета.
- **Приоритет актуальной ревизии**: для одного `title + memory_kind` остаётся
  максимальная `version`; это убирает противоречащее старое решение из контекста.
- **Подбор источников**: если есть реальные `matched` элементы, несовпадающие
  необязательные фрагменты больше не попадают в контекст как «похожие».
  Обязательные constraints/preferences сохраняются всегда.
- **Изоляция**: владелец B не попадает в контекст ни в одном из 5 сценариев;
  запрещённые факты (старое решение, удалённый черновик) также отсутствуют.

Тест на новой функции: `packages/core/test/context-evidence-scoping.test.ts`.

## Ограничение

Метрика `reference_precision` считается как `релевантные_ссылки / все_ссылки`
в сформированном контексте. Объём — байты JSON сформированного bundle, не токены
модели. Время измеряется на чистом отборе без ввода/вывода.
