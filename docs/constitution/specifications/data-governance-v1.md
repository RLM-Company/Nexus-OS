# Data Governance Synmetis AI v1

> Статус: `RESOLUTION DRAFT / NOT RUNTIME`  
> Дата: `2026-08-24`  
> Юридическая реализация требует проверки по странам запуска.

## 1. Классы данных

- `D0 PUBLIC` — законно доступные публичные данные.
- `D1 PROJECT` — обычные внутренние данные проекта.
- `D2 CONFIDENTIAL` — коммерческая тайна, закрытая переписка, внутренние документы.
- `D3 RESTRICTED` — секреты, платёжные данные, чувствительные персональные данные и регулируемые категории.
- `D4 PRIVATE_CHAT` — содержимое конфиденциального чата; постоянное хранение и обучение запрещены.

Класс наследуется производными файлами и может быть повышен, но не понижен агентом без отдельного решения ответственного за данные.

## 2. Доступ агентов

- Обычный агент имеет индекс памяти текущего проекта, но в активный контекст получает минимально необходимый сегмент.
- При полной замене ответственного агента новый агент получает полный разрешённый handoff проекта и резюме Менеджера.
- Глобальная память, другой проект и D2/D3 выдаются отдельным scope с целью и сроком.
- Критик получает те же минимальные сегменты, которые нужны для проверки, и не имеет постоянного скрытого доступа ко всей памяти.

## 3. Конфиденциальный режим

- D4 не сохраняется в памяти, индексах, чекпоинтах, аналитике и обучающих наборах.
- Разрешены только провайдеры из `confidential-compatible` routing group.
- Fallback за пределы группы запрещён.
- Временная обработка минимизируется и удаляется по техническому сроку; режим и провайдерская политика отображаются до отправки.

## 4. Право на обучение

Обучение допускается только если одновременно выполнены условия:

1. режим разрешён настройкой аккаунта и проекта;
2. применимый закон допускает выбранную модель согласия;
3. данные не относятся к D3/D4;
4. известен provenance;
5. пользователь имеет право разрешить такое использование либо данные прошли отдельную законную процедуру;
6. данные прошли фильтрацию секретов, персональных данных и запрещённого содержания;
7. назначение и срок включения в dataset зафиксированы.

Default-on там, где это законно, применяется только к **eligible data**, а не ко всем файлам проекта. Неясное право означает исключение до проверки.

## 5. Матрица настроек

- Конфиденциальный режим всегда запрещает обучение.
- Project OFF строже Account ON.
- Project ON не может отменить Account OFF без отдельного явного opt-in для проекта.
- Отзыв прекращает использование новых данных с момента вступления настройки в силу.
- Удаление исходника, исключение из будущих dataset и вклад в уже обученную модель показываются как разные операции.

## 6. Retention и удаление

Для каждой записи фиксируются primary storage, cache, vector index, logs, analytics, backups, trash и training dataset.

- Обычное удаление: корзина 30 дней.
- Немедленное удаление: step-up authentication.
- Primary, cache и index удаляются в заявленный срок.
- Backup удаляется ротацией с указанной максимальной задержкой.
- Неизменяемые финансовые и юридические журналы сохраняют минимальную обязательную запись без удалённого содержимого, если это требуется законом или аудитом.
- Система не обещает физическое удаление там, где действует обязательное хранение; показывает основание и срок.

## 7. Тариф и закрытие аккаунта

При downgrade или окончании оплаты владелец получает предупреждение, дату изменения retention, grace period и возможность экспорта. Данные не удаляются внезапно в момент платежного сбоя.

## 8. Экспорт и восстановление

- Экспорт требует повторной аутентификации и содержит манифест происхождения.
- Секреты не входят в обычный экспорт.
- Восстановление данных не возвращает разрешения, токены, A6 и активные интеграционные сессии.

## 9. Audit

Чтение глобальной памяти, межпроектный перенос, доступ к D2/D3, экспорт, удаление и включение в dataset журналируются с субъектом, целью, основанием и сроком.
