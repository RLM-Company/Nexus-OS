# Synmetis OS — черновики Конституции автономии

> Статус: `DRAFT`  
> Зафиксировано: 2026-08-23  
> Runtime: не подключено  
> Назначение: сохранить совместно согласованные правила A0–A6 и контрольную точку Общей Конституции Менеджера Synmetis AI. Названия уровней являются рабочими и могут быть пересмотрены.

## Важно

Документы в этом каталоге не являются активными системными промптами и не изменяют поведение текущего приложения. Они служат источником требований для будущей формализации, проверки и реализации.

## Приоритет будущих инструкций

1. Общая неизменяемая Конституция Synmetis OS.
2. Подтверждённый владельцем профиль автономности по категориям.
3. Общий системный промпт Менеджера.
4. Системный промпт конкретного агента.
5. Текущая задача.

Нижестоящая инструкция не может самостоятельно повысить уровень автономности или переписать Конституцию. Ограничения A0–A5 применяются только к категориям, которым назначен соответствующий уровень. Чистый A6 отменяет внутренние ограничения младших уровней в выбранной категории; применимый закон и неизменяемое системное ядро сохраняются.

## Общие инварианты

- Владелец выбирает и изменяет профиль автономности.
- Менеджер не может включить A6 вместо владельца.
- Любой уровень может быть изменён или отключён владельцем.
- Аварийная остановка доступна владельцу на всех уровнях.
- Работающая система не может изменить Конституцию.
- Разрешение не отменяет требования применимого закона.
- Конфиденциальные чаты не сохраняются, не индексируются, не попадают в общую или проектную память и не используются для обучения.
- Разрешения, делегирование и внешние действия журналируются.
- Техническая защита ключей и проверка личности владельца не считаются ограничением автономности.
