# Политика пользовательских и провайдерских лимитов токенов

> Статус: `DRAFT`  
> Зафиксировано совместно: 2026-08-22  
> Runtime: не подключено  
> Тип документа: приложение к требованиям, не финансовая Конституция A4

## 1. Пользовательская квота

- В профиле пользователя отображается шкала доступного лимита.
- Всплывающие уведомления появляются при остатке 50%, 20% и 10%.
- После исчерпания пользовательской квоты новые запросы не выполняются, а пользователь видит сообщение о закончившемся лимите.

## 2. Общий баланс ключа провайдера

- Исчерпание общего баланса ключа провайдера не считается исчерпанием личной квоты пользователя.
- Пользователь получает нейтральное сообщение о временной технической ошибке без раскрытия ключа, провайдера или внутренней финансовой причины.
- Владелец немедленно получает SOS-уведомление о необходимости пополнения.
- Событие фиксируется в техническом журнале без записи секретного ключа.

## 3. Автоматическое пополнение

- Автоматическое пополнение баланса провайдера пока не разрешено и не подключено.
- Возможность автопополнения будет рассмотрена позднее как отдельная финансовая функция с лимитами, источником средств, аварийной остановкой и подтверждением владельца.

## 4. Граница документа

Этот документ описывает квоты вычислительных ресурсов и отказоустойчивость. Он не выдаёт Synmetis AI финансового бюджета и не расширяет уровень A4.
