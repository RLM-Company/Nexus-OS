# Поиск по материалам проекта

Общий локальный поиск охватывает текущие текстовые артефакты Canvas, опубликованные
файлы завершённых Work, незабытые заметки памяти и готовые фрагменты библиотеки
документов. Он использует обычную сессию владельца, не вызывает модель, не сохраняет
новый индекс и не изменяет материалы. Новых элементов интерфейса этот блок не добавляет.

## Поиск

`POST /api/v1/projects/:projectId/knowledge/search`

```json
{ "query": "условия договора", "kinds": ["canvas", "work", "memory", "document"], "limit": 20 }
```

`kinds` необязателен (все четыре), `limit` — от 1 до 30. Это лексический поиск по
префиксам слов, а не семантический ответ или проверка истинности. Регистр, NFKC и
`ё/е` нормализуются для поиска, но цитата остаётся точным исходным текстом. Запрос
содержит до 200 символов, 16 различных слов длиной 2–80 символов. Неподдержанный
запрос отклоняется, а не молча сокращается. SQL и FTS-синтаксис пользователя не исполняются.

Каждый результат содержит:

- тип/ID источника, версию и SHA-256;
- точный фрагмент до 1200 UTF-16 code units, его начальную/конечную позицию и SHA-256;
- название, номер страницы (для PDF) и строки;
- совпавшие слова, признаки совпадения в названии/содержимом и лексический балл.

Позиции `start`/`end` — 0-based полуоткрытый диапазон в исходном тексте, не в его
нормализованной копии. Границы не разрезают surrogate pair или CRLF. Фрагменты
перекрываются при сканировании для слов на границе, но пересекающиеся результаты
одного текстового источника исключаются. На один Canvas/Work/заметку/документ
возвращается не более двух фрагментов, чтобы один длинный файл не занял всю выдачу.

Для Canvas берётся текущая ревизия. Для Work — только опубликованные файлы со
статусом работы `completed`; черновики и незавершённые работы исключены. Забытые
заметки исключены. Документы используют существующий FTS по нормализованному
индексированному содержимому; поиск только по имени файла не обещается.
В документной ссылке `version:null`, `chunk_id` указывает неизменяемый готовый фрагмент,
а `sha256` относится к этому фрагменту, не ко всему оригинальному PDF/DOCX.

## Охват и ограничения

Каждый запрошенный вид имеет собственный бюджет: Canvas/Work/документы — по 2 МБ
текста, память — 1 МБ. Большой источник пропускается целиком и отмечается в
`coverage.omitted_budget`. Повреждённый канонический Canvas/Work не выдаётся и
помечается `omitted_corrupt`. Метаданные Work читаются без загрузки всех тел файлов.

Охват сообщает доступность адаптера, число кандидатов/проверенных источников,
прочитанные байты и достижение предела кандидатов. Лимиты: 200 записей каталога
Canvas, 100 опубликованных файлов Work, 200 заметок и 1200 FTS-кандидатов документов.
`candidate_scan_complete` относится к проверке доступных кандидатов, а не к полноте
выдачи или всего знания проекта. `result_limit_reached` показывает достижение лимита
ранжированных результатов; балл не является вероятностью. Отсутствующий адаптер
показывается как `available:false`, без ложного «всё проверено».

Таблицы имеют отдельные API анализа/сводки; сообщения чатов — отдельный поиск истории.
Этот блок не читает GitHub, внешние сайты или локальные файлы компьютера.

## Подготовка выбранных цитат для чата и Work

`POST /api/v1/projects/:projectId/knowledge/context`

```json
{
  "references": [
    {
      "kind": "canvas",
      "id": "artifact-id",
      "version": 1,
      "sha256": "64 hex characters",
      "start": 0,
      "end": 100,
      "excerpt_sha256": "64 hex characters"
    }
  ]
}
```

Передайте `reference` из поиска, до шести различных фрагментов. API повторно читает
источник в том же проекте и проверяет версию, исходный хэш, диапазон и хэш цитаты.
Текст, название или права нельзя подставить в запрос. Чужой/удалённый источник даёт
404, изменённая память или неверный хэш — 409. Старая неизменяемая ревизия Canvas
остаётся доступной до удаления артефакта. После готового индексирования документный
фрагмент не перезаписывается; удаление файла отзывает возможность нового предпросмотра.

Ответ — обычное текстовое `attachment` с JSON цитат, происхождением и SHA-256.
Он явно говорит, что это выбранные фрагменты, не полные источники и не инструкции
или разрешения. Предпросмотр не сохраняет вложение и не отправляет его модели.
Его можно передать в существующие материалы проекта/сообщения. Принятие чата и Work
фиксирует снимок; дальнейшая правка или удаление исходника не переписывает уже
принятый контекст.

Общий лимит вложения — 8000 символов и 24000 байт. Если выбор не помещается, API
возвращает 413 без обрезания цитат или скрытого удаления элементов. Нужно выбрать
меньше фрагментов явно. Ответы поиска/контекста имеют `private, no-store`.

Миграций, новых зависимостей, платных запросов и фонового индексирования нет.
