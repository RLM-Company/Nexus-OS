# Гипотеза базовой подписки 990 ₽

**Исходная дата идеи:** 2026-08-22  
**Текущий статус:** `DEFERRED`

## Исходная идея

Ранний Synmetis archive фиксировал гипотезу базового тарифа около 990 ₽ и обсуждение подписки как основной модели монетизации.

## Почему отложено

Позже владелец отдельно решил не фиксировать тарифы до стабилизации продуктового набора и фактической экономики моделей/инструментов. Стоимости model API меняются, production provider не выбран, а набор функций Cosmora ещё развивается.

Поэтому цена 990 ₽ не является текущим requirement, обещанием пользователю или финансовой моделью.

## Что сохранить из идеи

Когда монетизация вернётся в roadmap, полезно проверить:

- subscription + optional top-up credits/tokens;
- unit economics по реальным input/output/tool costs;
- hard per-project/user usage ceilings;
- protection from runaway agent/tool spend;
- разные уровни model quality/latency без скрытого ухудшения безопасности;
- понятную пользователю стоимость long-running agent tasks;
- актуальные налоги, комиссии и regional pricing.

## Условие возврата

Сначала нужны: стабильный P0/P1 feature set, выбранный production routing strategy, реальные usage traces и целевой gross margin. После этого pricing проектируется заново с нуля, а 990 ₽ рассматривается только как историческая гипотеза.
