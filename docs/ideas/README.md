# Архив продуктовых идей Synmetis OS

> Статус: `IDEA / DRAFT`  
> Назначение: сохранять будущие идеи владельца до формального интервью, проектирования и переноса в спецификации.

## Правило архивации

Каждая новая продуктовая или архитектурная идея владельца сохраняется отдельной записью либо добавляется в существующую связанную запись.

Запись включает:

- дату и исходную формулировку;
- назначение идеи;
- связь с текущей архитектурой;
- уже принятые решения;
- открытые вопросы;
- статус;
- ссылку на будущую спецификацию или реализацию.

## Статусы

- `IDEA` — идея сохранена без утверждённой спецификации;
- `DISCOVERY` — идёт совместное интервью;
- `DRAFT` — собран черновик требований;
- `APPROVED` — владелец утвердил требования;
- `PLANNED` — включено в backlog;
- `IMPLEMENTED` — реализовано и проверено;
- `REJECTED` — идея отклонена, но история сохранена.

## Важное ограничение

Материалы архива не являются активными системными промптами, Конституцией или разрешениями runtime. Любая идея начинает влиять на продукт только после отдельного утверждения и реализации.
