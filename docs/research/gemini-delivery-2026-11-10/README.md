## Что адаптировано

Из `find-in-page-highlighter.cjs` взят сценарий буквального поиска текста.
Вместо прототипного движка добавлено действие `browser_find_text` в действующий
Chromium/CDP browser engine. Оно использует тот же reader, версию документа,
права, отмену и ограничения, что `browser_read_text`. Исправлен подход с
`toLowerCase().indexOf()`, который сдвигал позиции для некоторых Unicode-строк.
Сравнение идёт по исходной строке с экранированным literal regex; arbitrary regex
агенту не предоставляется. Контракт согласуется с API и native с обеих сторон.
[Поведение и приёмка](../../handoff/KOSWORK_BROWSER_FIND_2026-11-10_RU.md).
