# Планы Work

Создавайте шаги с зависимостями и запускайте готовые шаги вручную либо весь план с общим лимитом запросов. Ошибка не запускает платный повтор автоматически. Пауза и перезапуск сохраняют завершённые результаты; дальнейший запуск после перезапуска требует явного продолжения.

## Независимая копия

В сохранённом плане выберите **Создать копию плана**, задайте название и инструкции: исходный снимок Skills или текущий сохранённый выбор Work проекта. Копия сохраняет задачи, зависимости и требование Критика, получает новый ID и пустую историю выполнения. Попытки, артефакты, подтверждения, автоматический запуск и расходы не переносятся. Запуск — отдельное действие. Копию можно отредактировать до запуска.

Исходный снимок может содержать удалённые из каталога Skills; выбор явно показан в форме. При выборе настроек проекта берётся сохранённый выбор на момент создания копии. Источник и версия исходного плана сохраняются в `copied_from`. Изменения оригинала или копии независимы.

API: `POST /api/v1/projects/:projectId/work-dags/:id/clone`, тело `{client_request_id, expected_version, title, skills: "source"|"project", target_project_id?}`. Все проекты должны принадлежать тому же владельцу. Без `target_project_id` копия создаётся в исходном проекте; UI поддерживает этот вариант. Копирование из отменённого проекта в другой активный проект доступно через API. Неактивный/отменённый целевой проект отклоняется. Устаревший снимок отклоняется, повтор того же запроса возвращает ту же копию даже после удаления оригинала. Создание не вызывает модель.
