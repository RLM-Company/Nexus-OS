# Планы Work

Создавайте шаги с зависимостями и запускайте готовые шаги вручную либо весь план с общим лимитом запросов. Ошибка не запускает платный повтор автоматически. Пауза и перезапуск сохраняют завершённые результаты; дальнейший запуск после перезапуска требует явного продолжения.

## Поиск, названия и архив

В **Разделе планов** переключайтесь между текущими планами и архивом. Поиск работает по названию плана, названиям шагов и тексту задач без учёта регистра. Фильтр применяется внутри выбранного раздела.

**Переименовать план** меняет только заголовок: задачи, снимок Skills, результаты и разрешённое выполнение сохраняются. Переименование доступно и во время исполнения. Версия защищает изменения из другой вкладки; при конфликте черновик названия остаётся в форме. Закройте её и откройте заново для актуальной версии.

**В архив** сохраняет весь план, результаты, историю и принятые инструкции. Архивировать можно, когда автозапуск остановлен и все уже начатые попытки завершены, завершились ошибкой или отменены. Ожидающая подтверждения, приостановленная и находящаяся в очереди работа считается незавершённой. Архив не отменяет работу автоматически.

Архивные планы доступны для скачивания, просмотра инструкций и создания копии. Исполнитель пропускает их; изменение задач, переименование и команды запуска отклоняются. Проектные пауза/продолжение/отмена не меняют архивный снимок. **Восстановить план** возвращает его в текущий раздел и применяет нынешнее состояние проекта. Автозапуск остаётся выключенным; запуск или повтор требует отдельного действия. Если проект отменён, восстановление не снимает отмену.

Архив обратим и не является удалением. Общий предел — 100 сохранённых планов на проект, включая архив. Экспорт и удаление данных владельца охватывают оба раздела. При потере ответа на архивирование, восстановление или переименование интерфейс читает сохранённый план, не отправляя запись повторно автоматически.

API: `PUT /api/v1/projects/:projectId/work-dags/:id/archive` с `{expected_version, archived: true|false}`; `PUT /api/v1/projects/:projectId/work-dags/:id/title` с `{expected_version, title}`. Устаревшая версия даёт `409 STALE_DAG`. Архивные записи имеют `archived_at` и остаются в общем API-списке; разделы и поиск применяет интерфейс. Поля архива хранятся в существующей версии состояния, без новой миграции.

## Независимая копия

В сохранённом плане выберите **Создать копию плана**, задайте название, целевой проект и инструкции: исходный снимок Skills или текущий сохранённый выбор Work целевого проекта. Копия сохраняет задачи, зависимости и требование Критика, получает новый ID и пустую историю выполнения. Попытки, артефакты, подтверждения, автоматический запуск и расходы не переносятся. Запуск — отдельное действие. Копию можно отредактировать до запуска.

Исходный снимок может содержать удалённые из каталога Skills; выбор явно показан в форме. При выборе настроек проекта берётся сохранённый выбор на момент создания копии. Источник и версия исходного плана сохраняются в `copied_from`. Изменения оригинала или копии независимы.

API: `POST /api/v1/projects/:projectId/work-dags/:id/clone`, тело `{client_request_id, expected_version, title, skills: "source"|"project", target_project_id?}`. Все проекты должны принадлежать тому же владельцу. Без `target_project_id` копия создаётся в исходном проекте. Интерфейс позволяет выбрать другой собственный активный проект, в том числе для копирования из отменённого проекта. Неактивный/отменённый целевой проект отклоняется сервером. Устаревший снимок отклоняется, повтор того же запроса возвращает ту же копию даже после удаления оригинала. Создание не вызывает модель.

При сохранении в другом проекте интерфейс показывает ссылку на точную копию. Оригинал остаётся на экране. После потери ответа проверяется список целевого проекта; автоматического второго POST нет. Инструкции и материалы целевого проекта поступают при приёме каждого шага по обычным правилам Work; выбранный снимок личных Skills закрепляется при создании копии.

## Перенос через JSON

Ссылка **Скачать JSON плана** выгружает переносимый `kosmora.work-plan.v1`: название, задачи, зависимости и требование Критика. История запусков, файлы, сведения владельца, расходы, разрешения и тексты Skills в пакет не входят. Задачи могут содержать личные данные — проверяйте текст перед передачей файла.

В разделе **Перенос плана через JSON** выберите файл до 600 000 байт. Предпросмотр работает локально и показывает буквальный текст задач и зависимости. Перед сохранением отметьте, что проверили задачи. Импорт создаёт новый план с текущим сохранённым выбором Skills Work; модель не вызывается. Циклы, повторяющиеся ID, отсутствующие зависимости и дополнительные поля отклоняются независимо в браузере и на сервере. Файл не удостоверяет автора и не предоставляет разрешений.

API: `GET /api/v1/projects/:projectId/work-dags/:id/package`; `POST /api/v1/projects/:projectId/work-dags/import` с `{client_request_id, package}`. Повтор одного запроса не создаёт вторую копию; изменение содержимого с тем же ключом даёт конфликт. При потере ответа интерфейс читает список планов без повторного POST.
