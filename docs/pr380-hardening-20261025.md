# PR 380: experimental package review

This branch preserves the supplied architecture package. Its 160 catalog entries and generic field-transformation verifiers do **not** establish that 160 product features work. It remains a draft and is excluded from the presentation server release.

## Corrected in this revision

- Missing protocol imports, ambiguous barrel exports and exact-optional TypeScript errors were repaired. App Router page exports are valid.
- Enterprise signing and vault keys require an explicit 32-byte hex secret. Public defaults, padding and truncation are removed; malformed signed claims fail verification.
- The enterprise kernel requires an injected verified-session adapter. Input actor fields no longer manufacture an admin principal or MFA proof.
- F130 and F070 explicitly report unavailable domain adapters instead of fabricating row authorization or completed GitHub PRs.
- The experimental worker refuses host code execution. Detecting a Docker binary no longer counts as OCI isolation. Connect the existing production isolated executor before enabling this prototype path.
- SQLite analytics evaluates actual SELECT/WHERE/projection/aggregation/order over a bounded, explicitly supplied dataset. It has no fabricated default financial dataset or query plan; external SQL dialects require real adapters.
- Artifact history uses insert-only revision IDs and unique version slots, with database mutation guards. Snapshot restore preserves later revisions.
- The new workspace page shows a truthful integration state instead of hardcoded account/execution statistics. The separate old view-model remains a test fixture.
- A clearly synthetic vault test value replaces a key-shaped sample flagged by the repository scanner.
