# Koswork: полный ограниченный список вкладок

Последний найденный путь больших ответов: восемь разрешённых вкладок с URL до
4096 символов могли превысить лимит результата. Общая выдержка корректно
сообщала о сокращении, но идентификаторы последних вкладок исчезали из контекста.

`browser_tabs` теперь сохраняет идентификатор, заголовок и loaded всех вкладок
текущего Koswork browser engine. Адреса до 512 символов остаются точными `url`.
Для длинного адреса возвращаются `url_preview`, `url_excerpt_only=true`; общее
пояснение передаётся один раз на весь список: это не адрес для открытия, переключись по tab_id и прочитай актуальное
наблюдение с полным URL. Частичный адрес не выдаётся под именем `url`.
`complete_tab_list=true` относится только к вкладкам этого engine, не к другим
приложениям/профилям пользователя. Максимум по-прежнему восемь вкладок.

Заголовок сохраняет целый Unicode-префикс. State для пользовательского интерфейса
сохраняет точные URL; разметка/компоновка/стили не меняются. Исключение — исправление
разорванного Unicode в заголовке. Подтверждения, лимиты вкладок/живых views и
контроль свежести прежние; новых действий и прав нет.

Проверка: восемь URL длиной около 3500, все уникальные tab IDs сохранены в полном
JSON менее 12 000 UTF-8 байт; заголовок с emoji на границе цел. Выбор первой
вкладки по ID возвращает полный исходный URL, а не его preview. Обычные короткие
адреса покрыты действующими браузерными тестами. Windows-кандидат 0.21.3;
живой провайдер, установка владельцу и VPS не использованы.
