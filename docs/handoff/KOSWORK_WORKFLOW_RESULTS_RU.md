# Проверяемые результаты сценариев Koswork

## Поведение

В истории сохранённых сценариев добавлена явная проверка результатов запуска.
Она читает уже опубликованные файлы через существующую проверку размера и SHA-256
исполнителя Work. Новых обращений к модели, запусков кода и внешних действий нет.
Статус выполнения плана отделён от проверки ожидаемых результатов.

Ожидания берутся из неизменяемого снимка запуска, а не из текущей редакции
сценария. Автоматически сопоставляются только поддерживаемые буквальные имена
файлов. Описательные требования требуют ручной проверки; имена не угадываются.
Несколько файлов с одинаковым именем сохраняются отдельными версиями. Пустой
список ожиданий не считается успешно проверенным результатом.

## API и совместимость

- Библиотека сценариев дополнена capability `workflow_run_results.v1`.
- `GET /api/v1/projects/:projectId/workflows/:id/runs/:runId/results` выполняет
  точный поиск запуска по владельцу, проекту, сценарию и идентификатору. Работает
  и за пределами окна истории из 100 запусков.
- Проверяется принадлежность связанного плана. Ответ ограничен 2 МиБ и не
  содержит тел файлов, параметров запуска, инструкций планировщика, свободного
  текста критика или идентификаторов владельца/действующего лица.
- Архив использует существующий маршрут результатов Work; ссылка обозначена
  как архив, а не скачивание одного файла.
- Новый клиент показывает проверку только при наличии capability от API этого
  проекта. Старый API сохраняет прежние историю и скачивание.
- Запрос выполняется по нажатию, без фонового опроса файлов. При смене проекта
  или сценария запрос отменяется; поздний ответ не заменяет новый выбор.

## Пределы доказательства

Проверка опубликованных байтов не доказывает правильность содержания, выполнение
кода или принятие результата владельцем. Отзыв модели помечен отдельно и не
заменяет эти проверки. Интерфейс чата, сайдбар, оформление, права устройств и
миграции базы не менялись. Выкладка на VPS и проверка на реальном пользовательском
ПК не выполнялись в этом блоке.

## Проверки

Используются реальные Fastify/SQLite и исполнитель с тестовым ModelGateway:
зависимые файлы, отсутствие лишних запросов модели, снимок старой версии,
отсутствующие имена, одинаковые имена, описательные/пустые ожидания, чужой
проект/владелец, запуск за пределами истории и отказ при повреждении байтов.
Браузерные сценарии проверяют скачивание, обратную совместимость и поздний ответ
при переключении сценария. Модель провайдера и данные владельца не нужны.
