# Koswork: бюджет поиска по разделу и сквозная приёмка

Продолжение [поиска точной фразы](KOSWORK_VAULT_SECTION_SEARCH_2026-11-05_RU.md).

## Исправленная ошибка

Восемь совпадений не гарантируют ограниченный размер JSON. Управляющий символ
занимает один UTF-16 элемент, но сериализуется как шестибайтовый escape. Независимый
сценарий с 19 вхождениями допустимой 160-символьной фразы воспроизводил
`WORKSPACE_RESULT_TOO_LARGE` вместо результатов поиска.

Теперь `sectionMatches` проверяет фактические сериализованные UTF-8 байты всего
ответа после добавления каждого совпадения. Лимит внутреннего ответа — 10 000 байт;
оставлен запас для opaque paths и инструкции адаптера с общим лимитом 14 000 байт.
Количество совпадений по-прежнему не превышает восьми. Если очередное совпадение
не помещается, оно целиком переносится на следующую страницу: её offset указывает
на начало именно этого совпадения. Цитаты не сокращаются и не нормализуются.

Проверка обходит все страницы через настоящий `workspace_find`, сравнивает позиции
с исходником и подтверждает отсутствие пропусков, дублей и совпадения из соседнего
раздела. До исправления этот сценарий падал на первой странице; после него проходит.

## Полный рабочий цикл

Добавлен сценарий через действующие `ComputerSession` и `WorkCycleDriver`:

1. Поиск `contract.md` по имени, затем оглавление и выбранный раздел.
2. Первая выдержка ещё не содержит нужную фразу.
3. Первый поисковый scan-window пуст, но возвращает продолжение.
4. Ещё три страницы возвращают 19 точных вхождений `00123` без дублей.
5. Отдельное чтение последнего совпадения подтверждает `19 700 ₽, кроме доставки.`
   и SHA256 оригинала. Противоречащие `99 999 ₽, доставка включена` из соседнего
   раздела не попадают в выдержку.
6. Создаётся реальный `contract-report.md` в выбранной папке, после подтверждения
   записи. Затем файл читается обратно, сравнивается с ожидаемым содержимым,
   шаг отмечается проверенным, запуск завершается.
7. После завершения grant отозван, повторный поиск отклоняется.

Управление экраном или браузером не разрешается. Planner сценарный: проверены
реальный исполнитель, протокол инструментов и файловые операции, а не качество
живой модели. Платные провайдеры и ноутбук владельца не использованы.
