## Оценка готовности

Система готовится к личной альфе и демонстрации конкретных рабочих сценариев. Полный публичный сервис нельзя считать завершённым только по числу объединённых PR.

Открытые пункты на момент поставки `c8e742a` (последующие изменения — в `KOSMORA_FEATURES_2026-10-20_RU.md`):

1. Медиа: текущая интеграция не обеспечивает видео, параметры отличных от PNG 1024×1024 форматов и серверные референсы. Нужны реальные адаптеры и приёмка; отключённая кнопка не означает готовую генерацию.
2. Импорт XLSX: в обычном чате есть готовый пакет `38dff75f…`, но его ZIP-карточка в браузере не предоставляет скачиваемого URL. В текущую поставку он не включён; экспорт XLSX уже есть. Не заменять Workbench старым деревом ради импорта.
3. Windows: отдельный центр загрузок подготовлен в чате, но не входит в web/API-поставку. Реальная установленная GUI/DPAPI/installer lifecycle и подписанные обновления требуют отдельной приёмки. Исходники и ранее собранный unsigned installer не равны проверенному новому релизу desktop.
4. Work: блок приоритетов/сроков не имеет полученного готового результата; соответствующий чат остановлен. Готовые DAG, зависимости и библиотека планов сохраняются, но эти новые поля не объявляются реализованными.
5. GitHub Issues использует существующий токен и права; при отсутствии Issues permissions показывает отказ. Права автоматически не расширяются.

Следующий релизный шаг после этой поставки: короткая пользовательская приёмка основных маршрутов с доступной моделью, затем закрытие конкретных оставшихся блоков. Достоверного общего процента готовности без согласованного конечного списка функций нет.
