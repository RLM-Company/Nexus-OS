## Проверки на общей базе

Полный CI проверяет код и production Chromium. В общий gate дополнительно включена
существующая dev-репетиция с mock API и временной БД: она запрашивает главную и
проверяет функциональный сценарий, чтобы следующая поломка dev-resolver не прошла
только потому, что production-сборка работает. Production-таймаут браузерного теста
остаётся прежним. Проверка Koscode считает только запросы проектного API, а не
загрузки HTML и ресурсов страницы.
