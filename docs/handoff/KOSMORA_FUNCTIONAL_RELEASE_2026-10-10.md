# Kosmora — объединённая функциональная версия, 10 октября 2026

Этот документ описывает общий checkout `kosmora-integrated-v3` после объединения пакетов. Он дополняет более ранние handoff-файлы; заметки о том, что WorkDAG/Canvas ещё ожидаются отдельно, к этому snapshot уже не относятся. На рабочем VPS новая функциональная версия пока не активирована.

## Включённые функции

- Canvas в чате проекта: создание и редактирование артефактов, неизменяемые версии, восстановление как новая версия, локальный черновик с разделением владельцев, разрешение конфликта, экспорт. HTML отображается как текст, Markdown не загружает внешние ресурсы.
- Таблицы Studio: настоящий worker для CSV/TSV, типизация русских чисел, сохранение текстовых идентификаторов, фильтры/агрегация/диаграммы, полный CSV/JSON, явное сохранение рабочего файла и передача выбранных полных строк в чат. Парсинг можно отменить; невалидный новый файл не оставляет интерфейс занятым.
- Work: редактируемый план с зависимостями, запуск готовых шагов через Manager, версии выходных файлов, передача результатов зависимому шагу, пауза/продолжение и ручной повтор. Состояние и результаты переживают перезагрузку. Память проекта сохранена.
- Code: предложения по неизменяемому снимку репозитория, выбор файлов, редактор unified diff, серверная проверка применимости и исправление только количества строк hunk. Правка сбрасывает прошлую проверку и разрешение публикации. Потерянный ответ публикации сверяется с GitHub, а не отправляется повторно.
- Библиотека документов: сохранённые оригиналы, поиск фрагментов, ответы модели с проверенными ссылками на фрагменты, отдельные экспорты исходной подборки и сохранённого ответа.
- Исследования и история: синтез по полученным источникам и owner-scoped FTS с фильтрами.
- Общий учёт: один AccountStore, удержание до dispatch, сохранение неопределённого расхода и сверка с каноническим ledger без повторного списания.
- Операции с данными: обязательные адаптеры, экспорт бинарных оригиналов с manifest, durable fence от поздних записей; WorkDAG и Canvas включены в экспорт/удаление. Удаление требует продуктового подтверждения.
- Windows 0.11.2: восстановление черновиков, разделение серверов/владельцев, подтверждение принятого черновика и сохранённая сессия. Автообновления остаются выключены без закреплённого ключа подписания.

Последнее выложенное поведение поля ввода и приветствий сохранено при объединении. Новые изменения дизайна с 21st.dev этим этапом не внедрялись.

В повторном прогоне этих файлов 15/17 прошли; два media-сценария после уточнения проверки прошли отдельно. Все проверки этого этапа используют локальные фикстуры/mock-провайдер. Платных AI-запросов не выполнялось.

## Поставка

`node scripts/package-feature-release.mjs <абсолютный каталог вне checkout>` создаёт архив точного чистого Git-коммита и manifest с SHA-256 архива и каждого файла. Упаковщик отказывает при незакоммиченных изменениях, секретах, БД, .env кроме .env.example, ссылках, submodules и временных файлах. Он ничего не загружает и не выкатывает.

Порядок последних миграций: 25 → 26 → 27 → 28 → 30 → 31 → 32 → 34 → 35. Не заполнять пропущенные слоты выдуманными миграциями.

Перед активацией API/web на VPS нужна проверка копии текущей базы: консистентный backup SQLite и оригиналов, применимость offline bridges, официальные миграции и проверка запуска. Непустой старый retained ledger без run_id требует сверки и не может быть автоматически обнулён. При откате восстанавливаются и прежняя версия, и до-миграционная база с файлами. Служба входа, её сессии и настройки провайдера в этой поставке отдельно не меняются.

## Практические границы

- Настоящий Docker/OCI executor ещё не проверен. Проверка и публикация Code сохраняют отдельные разрешения; отсутствие executor не превращается в фиктивный PASS.
- Платные media остаются OFF; общий OwnerMediaBudget ещё нужно связать с каноническими ценами и реальным провайдером. Функция подготовки/экспорта промпта работает локально.
- Английский авторетранслятор по умолчанию OFF.
- Windows GUI/install/DPAPI/upgrade/uninstall ещё не подтверждены на установленном клиенте. Существующий installer 0.11.2 был собран до косметического форматирования исходников этого snapshot; его точное соответствие новому коммиту не заявляется.
- Новая функциональная версия не объявляется рабочей версией VPS до отдельной активации и проверки.
