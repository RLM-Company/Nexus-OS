# Kosmora: надёжное создание Skills

База: PR362, `d68e388f9bbbeb3041d824406e87899299b821a8`.

Создание/импорт получили опциональный Idempotency-Key. Сервер атомарно фиксирует
ID и SHA-256 нормализованных полей в отдельной owner-scoped записи. Повтор
возвращает актуальное состояние исходного Skill без изменения его версий;
смена полей под прежним ключом получает 409. Удаление оставляет tombstone (410),
чтобы сетевой повтор не воссоздавал удалённый документ. Одинаковый текст под новым
ключом создаёт независимую копию. Старые клиенты без ключа совместимы.

Миграция 0049 добавочная: прежние Skills и версии не переписываются. Ключи
неизменяемы, чужой Skill нельзя записать в receipt. Лимит 1000 ключей на владельца
включает tombstones; повтор обрабатывается даже при заполненной библиотеке.
Privacy export/delete включает ключи, очистка требует действующего fence;
повтор записи и чтение результата также соблюдают fence.

Браузер сначала получает авторизованное пространство аккаунта, затем читает только
соответствующую незавершённую попытку из sessionStorage. Ключ и текст сохраняются
и перечитываются до POST. Неподтверждённая запись в sessionStorage блокирует POST.
Потеря ответа сначала сверяется чтением receipt, без второго POST. Проверка после
reload только читает; явный повтор сохраняет прежний ключ и текст. Импорт при
повторе использует нормализованный текст уже просмотренного пакета. При успехе
получается актуальная серверная версия и только затем убирается локальная запись.
До завершения/сброса текст попытки доступен для экспорта, новые создания и правки
заблокированы. Сброс локальной попытки не удаляет Skill на сервере.

Ограничения: sessionStorage переживает reload/переходы в этой вкладке, но не её
закрытие или ручную очистку. Он не является общей библиотекой черновиков и не
сохраняет обычные несохранённые правки существующих Skills. Если локальный ключ
утрачен, надо проверить список перед созданием другой копии. Receipt API не
выдаёт текст чужих Skills и не меняет инструкции, уже закреплённые в chat/Work.

- Весь web unit прогон: 152 passed (13 новых случаев восстановления и хранения).
- Девять новых backend cases: миграция с 0048 и reopen, rollback записи receipt,
  fence, owner isolation, контроль содержимого ключа, tombstones, обе квоты,
  старые вызовы без ключа, схема HTTP/import и privacy export/delete.
- API/web/DB и выбранные E2E TypeScript; scoped ESLint; Prettier; secret/diff checks.
- DB/API production build и Next webpack build всех 19 routes.
- 11 browser-сценариев Skills обнаружены и проверены по типам, три новых и один
  обновлённый. Выполнение не подтверждено: Chromium отсутствует. Hosted CI pass
  не заявляется; у PR362 run 39158308017 завершился до первого шага, steps=[],
  runner_id=0, причина в доступном ответе не указана.

Новых зависимостей, вызовов модели, изменений бюджета/полномочий, main merge или
deployment нет. Историческое ограничение PR362 о неидемпотентном создании заменено
этим блоком; остальные функции библиотеки, Work, Canvas и презентаций сохранены.
