# Cosmora — контрольный пункт локальной альфы, 28 сентября 2026

## Подтверждённый рабочий путь

Проверка выполнена на отдельной временной SQLite-базе без `.env`, ключа модели и
платных запросов. `pnpm demo:preflight` подтвердил API, веб-прокси, состояние
mock runtime, отсутствие аварийной остановки и доступность основных страниц.
`pnpm manager:demo-smoke` через веб-прокси создал A2-проект, завершил план,
черновик и проверку Критика, скачал `result.md` и проверил сохранение состояния
и повтор запроса без второго запуска.
Повтор на действительно отдельной базе использовал `turbo run demo --env-mode=loose`,
чтобы тестовая переменная `DATABASE_URL` дошла до API. После smoke в том же
проекте создана вторая задача: API вернул обе записи в порядке создания, а
файл первой задачи остался доступен для скачивания. Обычный `pnpm demo`
по-прежнему рассчитан на локальный `.env`.

Это доказывает локальный mock-путь Manager, но не успешный ответ внешней модели,
произвольное выполнение графа задач или работу опубликованного статического сайта
с локальным API.

Дополнительно `manager:preflight` прошёл с кандидатом Registry для
`vibecode:gpt-5.5`, фиктивным локальным credential, отключённым mock fallback и
недоступным loopback-адресом модели. Проверены роли Manager, Analyst, Critic и
маршрут веб → API. Внешних запросов и расходов не было. Отдельный отрицательный
прогон подтвердил, что включённый mock fallback останавливает preflight до
любого вызова модели.

| Часть                  | Состояние                                           | Следующая проверка                                                                   |
| ---------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Локальный Manager demo | Mock smoke пройден                                  | Повторить на устройстве владельца                                                    |
| Live route             | Кандидат и non-paid preflight в PR #261             | Проверить провайдера без платного вызова, затем отдельно разрешить smoke             |
| Рабочий интерфейс      | Обновления в PR #262; статический приватный preview | Проверить в браузере с реальным API на локальном запуске                             |
| Проектный runtime      | Ограниченный путь plan → draft → Critic             | Отдельная работа для произвольного графа, делегирования и долговременного исполнения |

PR #261 и #262 открыты и не находятся в `main`. В обоих последних запусках GitHub
Actions задание `Verify monorepo` завершилось с failure без опубликованных шагов
и логов. Это пока не подтверждает ни успешность, ни ошибку проверки кода.
Локально для интерфейсного PR прошли форматирование, secret scan, lint,
TypeScript, unit/API tests и production build. Новые браузерные E2E в этой
среде не прошли из-за сбоя запуска Firefox; результат не объявляется зелёным.

## Порядок первого подключения живой модели

1. Убедиться, что нужные PR интегрированы после полноценного CI и проверки
   итогового diff. Не считать статический preview запущенным Manager API.
2. На локальном устройстве владельца поместить ключ только в `.env`, выбрать
   совместимый протокол и активную запись Registry, отключить mock fallback.
3. Запустить локальные API и веб через `pnpm demo`, выполнить
   `pnpm manager:preflight`. Этот шаг не вызывает внешнюю модель и теперь
   останавливается при mock fallback.
4. Только после этого отдельно разрешить `pnpm manager:smoke`: он отправит два
   платных запроса, один для обычного чата и один для проекта. Успех этих двух
   запросов ещё не доказывает полный автономный Manager runtime.

Не менять production provider, A6, финансы, внешние действия и секреты ради
обхода этих ворот. Следующая продуктовая работа после зелёной локальной альфы —
ограниченное выполнение задач с наблюдаемыми шагами, решениями владельца и
проверкой результатов Критиком по риску.
