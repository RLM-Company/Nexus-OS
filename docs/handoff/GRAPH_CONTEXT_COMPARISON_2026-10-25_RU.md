# Сравнение и скачивание контекста графа

Интеграционная база: `82b4636d9ab0bc02962ec3c436302e513dde2cd9`,
`codex/integrate-work-presentations-20261017`. PR #376 и #377 объединены в эту
ветку по поручению владельца; main и VPS не менялись. Дерево базы совпадает с
проверенным head PR377 (`d89afaadc0941c33e21184d3e4d4ceec164ed9d9`).

## Функции

После подготовки контекста можно сравнить его с сохранённым снимком. Чтение
статуса даёт точные query/revision сохранённого файла; затем загружается и
проверяется SHA-256 именно этого снимка, а не результат нового запроса на
старой ревизии. Версия материалов и хеш проверяются до и после чтения.
Несовпадение, неизвестный файл или отсутствующий снимок останавливают сравнение.
Функция ничего не записывает и не делает автоматических повторов.

Сравнение включает все поля снимка: метаданные, query, readiness/concerns,
лимиты поиска и пропуски, точные узлы и связи, версии/статусы, цитаты и ссылки
источников, все позиции/решения конфликтов и отметки устаревания. Порядок
сериализации ключей и коллекций узлов/связей не создаёт ложных изменений.
Разные `id@version` остаются отдельными записями, в том числе заменённые
источники; повторяющиеся точные ссылки отвергаются. Полные значения «Сохранено»
и «Просмотрено» раскрываются как текст React, не HTML. Новая проверка не
приравнивает совпадение или изменение статуса к доказательству истинности.

Перед сравнением подтверждение просмотра сбрасывается. После смены запроса,
загрузки другого снимка, проверки сохранения или успешной записи результаты
сравнения очищаются. Прежние review/hash/CAS и восстановление неизвестного
результата записи сохраняются.

«Скачать просмотренный JSON» сохраняет точные UTF-8 bytes attachment.content
под исходным именем, без переформатирования, модели или записи в материалы.
Контрольная сумма в панели относится к этому же просмотренному вложению:
это хеш JSON-массива `[name, content, source_type ?? null]`, а не отдельный
`sha256sum` скачанного файла. Подпись в интерфейсе уточнена.

## Проверки

- 235 web tests в 46 файлах, включая 25 новых случаев сравнения/чтения/рендера.
- 30 focused API/contracts cases, web и полный E2E TypeScript, scoped ESLint,
  Prettier, secrets/diff checks; production Next webpack build (20 страниц).
- Реальная HTTP-репетиция launcher из PR377 проходит в dev и production:
  импорт/HTML, hash, сохранение, API restart, stale, CAS, replace/remove и
  сохранность других материалов. Это не тест новых кликов в браузере.
- Добавлены три Playwright-сценария: сравнение без записи, отказ при изменении
  материалов и скачивание точных bytes. Integration discovery: 336 сценариев
  в 94 файлах. Выполнение не заявляется: повторный официальный install Chromium
  25 октября завершился повреждённым ZIP; исполняемого браузера нет.

Для выкладки на существующий VPS в этой сессии нет SSH host/config/key или
подключённого канала управления этим сервером. Поиск доступных deployment
плагинов не дал подключённого инструмента к существующему VPS; создавать
другой хостинг вместо него не стали. Hosted CI pass не заявляется.
