## Готовый операторский сценарий

`scripts/live-coscode-acceptance.mjs` работает только с loopback HTTP API и
существующей owner-session из закрытого окружения. Требует
`COSMORA_ALLOW_CODE_ACCEPTANCE=MODEL_TASK_AND_REVIEWED_DRAFT_PR` и абсолютный
`COSMORA_CODE_OUTPUT_DIR`. Реальные секреты не передаются через аргументы команд
и не включаются в отчёт.

Три явных действия задаются через `COSMORA_CODE_ACTION`:

1. `generate`: создать новый тестовый Code-проект со штатным разрешением локального
   выполнения, передать два точных пути исходников, запустить модель и автоматическую
   проверку существующих Node-тестов штатным изолированным исполнителем.
2. `collect`: только чтением забрать существующий запуск по заранее записанному
   client_request_id; новой генерации и публикации нет. Используется после потери
   ответа или разрыва соединения.
3. `publish`: после независимого просмотра и тестирования создать штатный review
   и Draft PR, проверить сохранённый результат и повтор запроса без новой генерации.

`generate` требует нового каталога: повторный запуск с тем же каталогом не отправит
вторую задачу. Потерянный ответ на POST не повторяется автоматически. Текущий
Code-сервис допускает до шести модельных tool-turns; сценарий не обещает один
модельный запрос, но требует одну попытку маршрута и отключённый fallback на mock.

`publish` требует точных значений `COSMORA_CODE_APPROVED_PROPOSAL_HASH` и
`COSMORA_CODE_INDEPENDENTLY_TESTED_SHA256`. Их задаёт интегратор только после
просмотра и независимого прогона. Это операторское подтверждение существующей
авторизованной задачи, а не новая глобальная настройка автономности.
Перед записью серверный снимок снова сверяется. Отдельный долговечный маркер
публикации блокирует повтор после неизвестного результата. В таком случае нужно
сверять результат через существующий Code reconcile/GitHub, а не удалять маркер
и повторять POST.

Штатные операции подтверждают точный review и одноразовый publication_token.
Сценарий не меняет существующие проекты, политику, provider credentials или
службу исполнителя. Точное предложение модели и результат проверки сохранены отдельно
от короткого отчёта; session/publication tokens в эти файлы не копируются.

## Независимая проверка кандидата

`scripts/acceptance/provider-completion-candidate.mjs` — явно запускаемый набор
из 16 Node-проверок. Он не включён в обычное обнаружение unit-тестов и требует
абсолютного пути кандидата в `COSMORA_CODE_PROPOSAL_CHECKER`.

После ручного просмотра модельного diff установить эту переменную на сохранённый
`provider-connection-check.proposed.mjs` и вызвать:

```text
node --test scripts/acceptance/provider-completion-candidate.mjs
```

Все HTTP-ответы внутри проверок синтетические, данные вымышленные. Сам кандидат —
исполняемый код: запускать после просмотра; при необходимости переносить этот
набор вместе с кандидатом в тот же изолированный OCI-исполнитель без сети.
Требование результата — 16/16; исходные тесты также должны остаться успешными.

Локальные проверки самого операторского сценария запускаются командой
`pnpm test:coscode-acceptance-guards` и включены в `check:core`.
Они используют синтетический HTTP-транспорт и не доказывают работу живой модели,
Docker или внешней публикации.

При подготовке прошли 8/8 Node-проверок операторского сценария и 76/76 существующих
API-проверок Code/GitHub на настоящих Fastify/SQLite с синтетическими внешними
транспортами. Первоначальный изолированный Windows-запуск API-тестов остановился
до выполнения тестов на EPERM при переименовании временного кэша; повтор вне этой
песочницы прошёл полностью. Scoped ESLint новых сценариев также прошёл.

## Текущий внешний блокер

При подготовке VPS 13.141.51.16 не ответил по HTTPS; SSH установил TCP-соединение,
но завершился тайм-аутом до получения SSH banner. Панель vm.h1cloud.net ответила
HTTP 200, однако отклонила ранее переданные данные входа. Владелец сообщил, что
сам решает доступ. Новых попыток аутентификации после этого не предпринималось.

Платная генерация, действительная проверка OCI и Draft PR через Coscode в этом
проходе ещё не запускались. Ни стоимость, ни скорость, ни готовность живой цепочки
не объявляются подтверждёнными.
