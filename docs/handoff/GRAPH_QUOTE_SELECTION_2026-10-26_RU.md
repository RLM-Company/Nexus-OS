# Выбор замены исчезнувшей цитаты

Продолжение PR384, база интеграции 0e30b409cdf5c2edb4438e9fb4774c41bc134c5c.
Код пакета Gemini не изменяется.

В сверке исторической цитаты можно нажать «Выбрать новый фрагмент». Поле только
для чтения содержит действующую версию того же источника. Выделение мышью или
клавиатурой принимается отдельной кнопкой. Поддерживаемый узел показан с точной
версией и полным текстом, чтобы сопоставить смысл нового фрагмента.

Отступы и переводы строк сохраняются буквально: offsets textarea с LF
отображаются обратно на исходные CRLF/CR/LF. Индексы считаются в UTF-16,
границы внутри surrogate pair, пустой текст и более 1000 исходных символов
отклоняются. Unicode и HTML не нормализуются и выводятся текстом React.

Выбор нового фрагмента очищает место и подтверждение. Сохранение требует нового
места и явной сверки. Отмена выбора возвращает режим исходной цитаты, только
если она присутствует в новой версии. Удалённый источник или уже действующая
цитата не открывают перенос. Используется прежний cite_edge с revision CAS;
новая связь остаётся непроверенной, прежняя цитата сохраняется в истории.
При неизвестном результате нет автоматического повтора записи.

Проверено: 284 web-теста, 84 focused core/API-теста, web/E2E TypeScript,
scoped source ESLint, 9/9 dev Chromium сценариев через настоящий API/SQLite.
Два новых браузерных сценария проверяют замену с CRLF/Unicode/HTML, отсутствие
записей до подтверждения, историю и сброс подтверждения при смене выделения.
API использует local development identity/mock provider; это не deployed auth.
Production acceptance выполняется после следующей функции на итоговом дереве.
