# Intelligence Graph visual navigation

Stacked on graph authoring PR #365. This is a read-only workspace UI addition; API/storage/contracts and knowledge fixtures are unchanged. Runtime integration remains OFF.

- Deterministic monochrome SVG map of the actual active nodes/edges, including exact endpoint versions. Deleted/superseded records and stale endpoint versions are omitted. No relationships are generated by layout.
- Keyboard/click node selection, exact text/status panel, incoming/outgoing links, neighbour navigation, one-hop focus, bounded zoom/pan and reset. Large views hide most labels until selection; source text remains available in the panel.
- Breadth-first shortest recorded paths (0–6 edges), explicit outgoing/either direction, reverse traversal labels and highlighted original edges. A navigation path does not establish causal or logical entailment.
- Connected components, isolated nodes, explicit CONTRADICTS relations, claims without a direct Source/Document neighbour and strongly connected groups in DEPENDS_ON. These are structural observations, never automatic truth verification, repair or new evidence. A cyclic group can contain multiple simple cycles.
- Existing editor, literal search, portable imports, revision comparisons and verification states are preserved.

Validation: 8 new pure navigation/diagnostic cases passed; the parent has 195 focused passing cases. Web and E2E TypeScript, scoped ESLint/Prettier, diff/secret checks, Playwright discovery (4 scenarios) and Next webpack production build (12 generated pages) passed. The standalone web typecheck was run after the production build to avoid concurrent writes to .next/types. Browser execution is not claimed: Chromium is absent. No model calls, source-data expansion, main merge or deployment.
