# Kosmora: правки, поиск и проверка восстановления презентаций

База: PR360, `b54d5da510372e6f72056149ff4f50ca54eb63b4`.
Изменения ограничены редактором презентаций, его тестами и этим документом.
Соседние задания XLSX import / Canvas search / Work priorities / Code issues /
Reader / Windows downloads не реализуются повторно.

## Поведение

- Отмена и повтор текста, темы, макета, заметок, добавления, удаления, копирования
  и перестановки слайдов. Ввод в одном поле группируется до ухода фокуса.
  Ctrl/Command Z, Shift Z и Ctrl/Command Y работают в редакторе; поля поиска
  сохраняют собственную нативную отмену. Поиск сам по себе не создаёт правку.
- Снимки содержат только редактируемые поля и выбранный слайд. Undo после Save
  сохраняет актуальные серверные version/identity/provenance. Возврат к точному
  сохранённому содержимому снимает dirty. Новая правка очищает redo.
- Локальная история: максимум 40 снимков и 8 MiB оценочного UTF-16 JSON в каждом
  направлении. Она живёт только в памяти вкладки. Открытие, импорт, создание,
  удаление или серверное восстановление очищают историю. Reload её не сохраняет.
- Буквальный поиск по заголовкам, тексту, вторым колонкам и (по явному выбору)
  заметкам. Все слайды или текущий, с учётом регистра или без него. Переход
  выделяет совпадение в поле. Скрытый текст второй колонки доступен для правки.
- Замена одного совпадения или всех после явного просмотра. Подтверждение связано
  с точным содержимым, областью поиска и заменой. Массовая замена — одна отменяемая
  правка, без API-записи. Регулярные выражения и интерполяция `$&` не применяются.
  Сохраняются пробелы, Unicode и CR/LF. Ограничения полей/пакета проверяются до
  изменения; частичных замен нет. До 10 000 совпадений, в списке первые 100;
  при превышении лимита замена запрещена. Поиск/замена до 4000 символов.
- Перед восстановлением показано сравнение с открытым черновиком: все поля,
  заметки, добавленные/удалённые слайды и их позиции, сопоставление по ID.
  Длинный текст явно сокращён до 500 символов; выбранная версия доступна в JSON.
  После локальных правок требуется новое подтверждение. Серверный expected_version
  остаётся привязанным к проверенному состоянию, чужая правка вызывает конфликт.
- Потерянный ответ PUT: один GET проверяет тот же ID, точную следующую версию и
  всё содержимое (с серверным trim заголовка). Совпадение подтверждает сохранение;
  иначе исходная ошибка и локальный черновик остаются. Автоматического второго
  PUT нет. Восстановление старой версии и создание не получают такую сверку.

## Проверки

- 125 web unit cases, включая 20 новых проверок истории, поиска/замены,
  сравнения и восстановления сохранения: passed.
- 12 API tests в presentations / presentation-history / presentation-work: passed.
- Web и selected E2E TypeScript, scoped source ESLint, Prettier и secret scan: passed.
- Contracts build и Next webpack production build, 19 routes: passed.
- Четыре новых Playwright сценария и обновлённый history-сценарий обнаружены,
  типы проверены. Выполнение не подтверждено: Chromium не установлен;
  стандартный installer возвращает повреждённый ZIP (central directory missing).
  Предыдущие браузерные результаты PR360 не считаются проверкой новых изменений.

Новых зависимостей, миграций и вызовов модели нет. Серверные права, бюджет и
провайдеры не меняются. Main merge и deployment не выполнялись. Локальная копия
частичная; публикация использует полное base_tree PR360 и проверенные blob SHA
изменённых файлов, сохраняя все нетронутые пути удалённой базы.
