## Изменения

- Переключатель нового чата: кнопки 36 px внутри панели 46 px; центр шапки на desktop, отдельная центральная строка на мобильном без перекрытия названия и настроек.
- Логотип: собственный SVG космонавта и кольца без заливки, рамки и пересекающих визор петель. Цвет currentColor.
- Многоточие: панель через React portal вне обрезающего контейнера, положение ограничено окном и пересчитывается при изменении размера и прокрутке; Escape, внешний клик, клавиатурный фокус. Иконка у каждой команды: открыть, закрепить/открепить, переименовать, скопировать приватную ссылку, скачать Markdown/JSON, архивировать, удалить с подтверждением. Экспорт читает фактическую переписку с сервера без AI.
- «Создать проект» — первая строка раскрытого списка проектов. Нативный модальный диалог, существующий POST /projects/empty с UUID, повтор с тем же ID и сверка после потери ответа; создание не запускает модель.
- Изображения и видео: описание, стиль, формат, локальные референсы (до четырёх PNG/JPEG/WebP по 5 МБ), отдельный результат. Для видео также длительность. Настройки раздельно сохраняются в sessionStorage, изображения референсов остаются только в памяти вкладки и освобождаются при удалении/уходе. Текстовый «готовый промпт» больше не выдаётся за результат генерации.
- Генерация изображений использует существующий серверный маршрут и историю; запуск требует готовой capability и явного согласия на расход баланса. Добавлена защита двойного клика, пока POST ещё не вернул job.
- Sound открывает реальное озвучивание, воспроизведение и сохранённые записи.

## Границы готовности медиа

У текущего API изображений один выход PNG 1024 × 1024; стиль передаётся в описании. Форматы кроме 1:1, генерация по референсам и видео требуют расширения серверного адаптера. Интерфейс позволяет подготовить параметры, но блокирует запуск неподдерживаемой операции и сообщает конкретную причину. Новые внешние провайдеры, ключи, платные запросы и маршруты API в этом изменении не включаются. Просмотр локальных референсов не загружает их на сервер.
