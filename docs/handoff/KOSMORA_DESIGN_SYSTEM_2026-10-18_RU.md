# Kosmora: единый интерфейс по подборке 21st.dev

База — `b54d5da` (объединённые Work, Skills, Canvas, презентации и уже развёрнутый Excel). Из 26 присланных команд выделены 24 уникальных референса. Повторы `share-file-dialog` и `import-patchbay` учитываются один раз.

## Способ интеграции

Открытые карточки всех 24 компонентов прочитаны через официальный WebMCP `read_21st_page_markdown`, визуальные превью просмотрены выборочно. Реестр `/r/…` без API-ключа возвращает 403; интерфейс 21st показывает две оставшиеся бесплатные разблокировки исходников. Разблокировки не использованы, ключи и подписки не создавались. Полные реализации из платного/ограниченного раздела не получены и не скопированы. Ни одна команда установки `npx shadcn` не запускалась.

В репозитории выполнены самостоятельные адаптации общих визуальных и интерактивных приёмов на существующих React, TypeScript и CSS Modules. Новых пакетов, удалённых шрифтов и runtime-запросов к 21st нет. Лицензия карточки не трактуется как разрешение на закрытый исходный код; для карточек с unknown/no-license использованы только общие идеи интерфейса.

## Сведение и оставшиеся экраны

- Чёрно-белые токены, единые радиусы, размеры отступов, моноширинный шрифт для кода, читаемые маленькие подписи.
- Canvas, personal-settings и presentations приведены к общей типографике и контролам. Цвета самого создаваемого документа/слайда относятся к содержимому и сохранены.
- Медиаэкран больше не выбирает отдельную чёрную панель по теме ОС; использует токены приложения.
- Studio: единые загрузки, явная связь исходного столбца и типа, строка фильтров, карточки метрик, таблица с закреплённой шапкой/индексом.
- Ошибки, состояния загрузки, пустые коллекции, touch44px, фокус и reduced-motion предусмотрены в новых компонентах.
- Сохранены: модель слева в composer, микрофон у отправки, ПКМ для голосового режима, настройки чата сверху справа, меню режимов под брендом. Выбор чата не меняет сортировку.

## Для дальнейшей разработки

`ui/workspace-kit.tsx`, `code-window.tsx`, `inline-diff.tsx`, `terminal-output.tsx`, `editor-toolbar.tsx`, `work-plan-view.tsx`, `activity-timeline.tsx` — используемые общие компоненты, пригодные для следующих функций. Хост владеет правами, хранением и API-действиями. Не добавлять фальшивые статусы, публичные ссылки, режимы модели или отправку в AI ради демонстрации дизайна.

XLSX-import, большой документный reader и GitHub Issues остаются отдельными функциональными задачами параллельных чатов. Их завершение этим дизайн-проходом не утверждается; новые визуальные компоненты можно применять к ним при интеграции.

## Проверки

На локальной изолированной SQLite-базе и mock-провайдере. Платных запросов нет.

- Web unit: 119/119, 26 файлов.
- Браузерный первый проход: 50/56; после исправлений затронутый набор 16/16, включая новый сценарий Enter в поиске модели. Итого проверены 57 уникальных сценариев; это два прохода, не единый результат 57/57.
- Полный web TypeScript и scoped ESLint проходят. Производственная сборка, репетиция миграций и фактическая активация записываются ниже после выполнения.
- Исправлены найденные регрессии: Enter в модельном поиске не отправляет форму чата; ошибка применения ячейки видна в модалке; закрытие возвращает фокус; загрузка позволяет заменить файл во время чтения; закрытые share-окна не дублируют имена файлов в DOM.
