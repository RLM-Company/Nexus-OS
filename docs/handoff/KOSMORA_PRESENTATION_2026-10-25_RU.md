# Локальная репетиция Kosmora к показу 25 октября

База: PR #376, `b291cd1b238dc5a46f8c8ccecd69a2c67719d9d8`.

## Запуск на компьютере для показа

Нужны Node.js 24+ и установленные зависимости репозитория. Если зависимости
ещё не установлены: `pnpm install --frozen-lockfile`.

Из корня репозитория:

```sh
node scripts/presentation-demo.mjs
```

Команда сама запускает настоящий API и Next.js на `127.0.0.1` (порты 3310 и
3300), выполняет управляемые миграции отдельной демонстрационной базы, создаёт
проект через обычный HTTP API и импортирует граф. Прямые ссылки на граф и
проект выводятся в терминале. Дождитесь этих ссылок, откройте граф заранее,
чтобы компиляция страницы завершилась до выступления.

Режим модели — **mock**. Первый ответ проекта — локальный синтетический ответ,
не доказательство качества внешней модели. Подготовка/просмотр графа и снимка
не запускают модель. Скрипт не читает `.env` для API, не наследует credentials,
registries, sidecar settings и NODE_OPTIONS. Платные медиа отключены. Публичный
доступ и LAN не включаются. Обе команды ниже относятся к локальной репетиции,
не изменяют работающий VPS и не подтверждают готовность платных провайдеров.

Данные сохраняются в `.tmp/presentation-demo`, отдельно от обычной базы.
Повторный запуск открывает тот же проект и граф, сохраняя пользовательские
правки; повторное заполнение не выполняется. `Ctrl+C` завершает API и web.
Занятые порты и уже работающий launcher приводят к отказу, подключения к чужим
процессам нет. После аварийного завершения можно убрать **только**
`.tmp/presentation-demo/launcher.lock`, предварительно остановив оставшиеся
процессы. Базу удалять для исправления запуска не нужно.

## Проверка перед выступлением

```sh
node scripts/presentation-demo.mjs --check
```

Создаётся новая временная база. Скрипт проверяет mock runtime, web-to-API proxy,
импорт и HTML страницы графа, SHA-256 контекста, отсутствие записи при просмотре,
сохранение, реальный перезапуск API, устаревание после новой ревизии, отказ
при старой версии материалов, замену и удаление снимка с сохранением остальных
файлов/инструкций. При успехе выводится `HTTP rehearsal PASS`, серверы
останавливаются, временная база удаляется. При ошибке логи сохраняются по
напечатанному пути. Это HTTP-проверка, не имитация браузерных кликов.

## Показ на заранее собранном приложении

Чтобы убрать компиляцию страницы во время выступления, заранее соберите
текущую ветку (`pnpm build`), затем:

```sh
node scripts/presentation-demo.mjs --check --production --api-port=3100
node scripts/presentation-demo.mjs --production --api-port=3100
```

При обычной сборке Next.js запоминает API `http://127.0.0.1:3100`. Изменение
переменной после сборки не переписывает proxy. Launcher проверяет
`routes-manifest.json` **до** запуска процессов и записи данных и отказывается
запускаться при несовпадении. При другой конфигурации сборки задайте её порт
через `--api-port=...` либо пересоберите web с нужным COSMORA_API_ORIGIN.
Для другого web-порта используйте `--web-port=...`.

## Короткий сценарий показа

1. Откройте напечатанную ссылку на граф. При первом запуске там семь записей
   и шесть связей. Три источника — реальные файлы этого checkout с точными
   цитатами, строками и SHA-256. Импорт оставляет записи непроверенными.
2. Выберите источник и покажите цитату, статус и связанную запись.
3. В блоке «Контекст графа для модели» введите `контекст`. Подготовьте снимок,
   покажите его ревизию, состав, ограничения и контрольную сумму.
4. Просмотрите материалы, отметьте подтверждение просмотра и добавьте снимок
   в материалы проекта. Остальные заметки сохранятся.
5. Перезагрузите страницу и снова откройте граф: сохранение обнаружится без
   повторного ввода запроса. Это чтение из SQLite, а не восстановление картинки.
6. Измените название графа, сохраните новую ревизию. Покажите сообщение об
   устаревшем снимке и подготовьте актуальную версию. Замена выполняется только
   после нового просмотра и подтверждения.
7. При необходимости откройте историю ревизий или уберите снимок из будущих
   запросов. Это не меняет материалы уже созданных запусков.

Не выдавайте граф знаний за параметры обученной нейросети, mock-ответ за
живую внешнюю модель или наличие связи за доказательство истинности тезиса.

## Исправление обнаруженного блокера

HTTP-репетиция выявила dev-only HTTP 500 в `/graph-workspace`: новая проверка
статуса импортировала runtime-функцию из общего barrel `@cosmora/contracts`.
В development это тянуло TypeScript index с `.js` re-exports, которые webpack
не разрешал. Добавлен узкий subpath `@cosmora/contracts/intelligence-graph-context`
с существующими development/types/default условиями, панель использует его.
Глобальные настройки bundler, чат, сайдбар и бренд не менялись.

## Проверки этой поставки

- Пять Node tests: изоляция окружения, порты, точность источников, отказ при
  изменённой цитате, проверка production proxy до запуска.
- 30 focused API/contracts cases и 210 web tests; web TypeScript и scoped ESLint.
- Реальный HTTP-сценарий с API restart прошёл в dev и production.
- Повторный запуск/остановка восстанавливают те же project/graph IDs без
  повторного заполнения; очистка lock и штатное завершение процессов проверены.
- Production build, форматирование, secrets и diff checks проверяются перед
  фиксацией. Браузерные клики не заявляются: официальный загрузчик Chromium
  получил повреждённый архив, исполняемого headless shell в окружении нет.

Hosted CI и браузерную приёмку нужно отличать от перечисленных локальных
проверок. Прежний PR #376 имел CI failure до выполнения шагов; этот скрипт
не устраняет отсутствие GitHub runner.
