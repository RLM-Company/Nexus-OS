# Поиск Canvas и проверяемые переходы к источникам

Следующий проход по согласованному блоку документов. Главный экран и сайдбар не менялись. API, база и зависимости не требуют обновления.

## Canvas

- Поиск буквального текста с Unicode, учётом регистра и перемещением по совпадениям. Символы регулярных выражений рассматриваются как обычный текст.
- Замена одного или всех совпадений; `$&`, `$1` и обратные слеши в замене сохраняются буквально.
- Отмена и повтор последней замены доступны только пока текст совпадает с соответствующим снимком. Промежуточную ручную правку эти действия не перезаписывают. Состояние сбрасывается при переходе к другому артефакту.
- Массовая замена не выполняется при более чем 10 000 совпадений: интерфейс просит уточнить поиск. Превышение 512 КиБ и нулевой символ отклоняют замену целиком.
- Ctrl/Cmd+F или H перехватываются только внутри редактора Canvas и его панели поиска; Escape закрывает поиск, сохраняя открытый документ.

## Библиотека

Поиск документов по имени, фильтр состояния, выбор и снятие выбора видимых готовых файлов, общий сброс. Выбранные скрытые файлы сохраняются; их число явно показано. Один ответ модели ограничен 20 выбранными файлами по существующим правилам API; поиск и архив оригиналов сохраняют свой прежний смысл.

У результатов поиска и источников сохранённого ответа появились переходы к оригиналу по `file_id`, странице и строкам. Одинаковое имя файла не используется для угадывания оригинала. Если оригинал удалён или ID отсутствует у старого ответа, остаётся сохранённый фрагмент и явная отметка недоступности.

Длинный текст оригинала показывается частями по 20 000 UTF-16 единиц без разрыва суррогатных пар. Поиск и цитата автоматически открывают соответствующую часть. Подсвечиваются искомый текст или исходные цитируемые строки; учитываются LF, CRLF и CR. Перед подсветкой источника фрагмент сверяется с текстом указанных строк. При расхождении интерфейс не выдаёт другую строку за цитату.

Исправлена ошибка привязки отчётов: изменение поля вопроса после поиска больше не переименовывает старую подборку. Экспорт, отправляемый контекст и копия Canvas сохраняют запрос, фактически породивший результаты.

## Проверки

115 модульных проверок web и 10 регрессий таблиц. Пройдены 6 браузерных сценариев нового поиска, цепочки файлов/Canvas и библиотеки; отдельно повторяются 10 существующих сценариев Canvas и 2 новых сценария с проверкой реальной видимости подсветки. Проверяются буквальные замены, отказ при переполнении, отмена/повтор, защита ручной правки, сохранение артефакта, скрытый выбор, переход по ID к поздним строкам большого документа и сохранённым источникам.

Данные браузерных тестов синтетические, API и SQLite локальные. Платные AI-запросы не выполняются. TypeScript и ESLint затронутых исходников проверяются перед сборкой. Полный исторический набор других функций этим отчётом не объявляется пройденным.

Визуальные подходы: `kuratlielia/filter-toolbar` для действий над видимой выборкой, `bankkroll/file-viewer` для чтения оригинала, `uvain/rich-text-editor-toolbar` для локальных действий Canvas. Новые оболочки навигации и внешние установщики не использовались.
