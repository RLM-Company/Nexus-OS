# B5. Действия обычного чата Kosmora

База `8ed117f87454cd7e1d0c0cf51542dbcf027df544`. Ветка
`feature/kosmora-chat-actions`.

В текущей базе уже были WebSearch, параметры учебных действий и сохранение
метаданных в SQLite. Эта поставка использует существующую отправку сообщений,
очередь ответа и модель обычного чата.

- **Поиск.** «Искать в интернете» у завершённого сообщения создаёт запрос
  в том же чате. Текущий черновик и его вложения сохраняются. WebSearch получает
  первые 240 символов нормализованного запроса. Найденные фрагменты передаются
  модели как внешние данные. Пустая выдача и недоступность дают разные сообщения
  и останавливают этот запрос до вызова модели.
- **Учёба.** В меню действий доступны объяснение, подсказка, пошаговый разбор
  и проверка ответа. Выбранное действие имеет приоритет над автоматическим
  распознаванием запроса на изображение.
- **Переписывание.** Выделить текст в поле ввода, выбрать «Переписать текст»,
  задать тон и объём и отправить. Исходное выделение доступно в истории рядом
  с ответом «Новая версия». Пустое выделение и фрагмент длиннее 8 000 символов
  требуют исправления перед запуском действия.
- **Восстановление.** Кнопка возврата запроса в редактор после отмены или ошибки
  восстанавливает текст, вложения и параметры действия. В HTTP-схеме появились
  необязательные поля действий, которые уже хранились в SQLite.

## Примеры из браузерной фикстуры

| Действие           | Результат                                                         |
| ------------------ | ----------------------------------------------------------------- |
| Искать в интернете | Код архива — B5-047. [Демо-архив](https://example.org/b5/archive) |
| Объяснить          | Дисперсия показывает разброс значений вокруг среднего.            |
| Дать подсказку     | Сначала раздели обе части уравнения на 2.                         |
| Разобрать решение  | Разделим обе части на 2: x + 3 = 5. Вычтем 3: x = 2.              |
| Проверить ответ    | При x = 3 левая часть равна 12. Верный ответ x = 2.               |
| Переписать         | «Ответьте, пожалуйста, сегодня.» → «Просим ответить сегодня.»     |

Первый браузерный прогон выявил потерю метаданных из-за схемы ответа Fastify.
Добавлена регрессия по HTTP-ответу и истории. Приёмка выполняется на
модельной фикстуре и ответах WebSearch со ссылкой, пустой выдачей и HTTP 503.
Живой провайдер и внешний индекс в этой приёмке не используются.

Миграции и зависимости не требуются. Откат через revert коммита.
