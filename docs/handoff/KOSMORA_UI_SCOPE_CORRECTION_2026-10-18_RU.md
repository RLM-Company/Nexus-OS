# Исправление границ UI-обновления Kosmora

По прямому указанию владельца отменён общий визуальный редизайн из `7293813`. Подборка элементов не разрешает менять боковое меню, основную страницу, компоновку чата и ранее внедрённые компоненты.

## Что возвращено

Внешний вид sidebar, меню режимов, верхней панели, главной страницы и Work-обзора, composer, выбора модели, настроек аккаунта, презентаций и медиараздела возвращён к базе до последнего дизайн-прохода. Восстановлены прежние дерево файлов, окно кода, вкладки файлов, Markdown-код чата, GitHub-рамка, оформление Code и Canvas. Общие `globals.css`, `ui/interface-system.css`, `workspace-sections.module.css`, `workspace-navigation.*`, `page.tsx` и `ui/kosmora-controls.*` совпадают с `b54d5da`.

Старая подборка проверена по исходному вложению `8143afe7-904b-43d4-9748-61cba7a95a09/Вставленный текст.txt`. В ней уже были sidebar, dropdown-navigation/menu, `jatin-yadav05/file-tree`, `ddoemonn/tree-view`, `ayushmxxn/code-block`, ball-model-picker, switch, shining/streaming text, pricing, chat input, ai-planning/agent-pipeline, system-message и voice orb. Новые варианты тех же элементов не заменяют прежние.

## Что остаётся новым и локальным

- Терминал фактических stdout/stderr и новый inline diff — только внутри проверки и просмотра изменений Code.
- Markdown-панель форматирования — только в редакторе Canvas, без изменения его компоновки и общего оформления.
- Переходы по этапам — только в открытом редакторе плана Work; timeline — внутри раскрываемого журнала событий. Существующая панель выполнения и список шагов возвращены.
- Загрузка, поиск, фильтры, список/сетка и диалог owner-scoped ссылки — внутри библиотеки документов Studio.
- Активные фильтры, образцы сопоставления столбцов и диалог редактирования ячейки — внутри таблиц Studio. Прежние размеры метрик и оформление таблицы восстановлены.
- Кнопки и диалоги реализованы в изолированных CSS Modules. Общий слой интерфейса не меняется.

API, база, миграции, учётные данные и оплачиваемые модели этим исправлением не изменяются. Новые глобальные меню, пункты навигации и декоративные dashboard-карточки не добавляются. Последующие подборки внедряются как недостающие части отдельных функций; существующие sidebar, главная и composer остаются защищённой областью до отдельного запроса владельца.
