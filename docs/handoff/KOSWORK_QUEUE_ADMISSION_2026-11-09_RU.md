# Koswork: доступные задачи не скрываются за заблокированной очередью

## Проблема

Планировщик читал первые 50 задач со статусом `queued`, затем проверял блокировки
владельца и пытался получить право исполнения. Если все 50 задач принадлежали
заблокированному владельцу, они занимали ту же выборку на каждом такте. Доступная
задача другого владельца за пределами этого окна никогда не доходила до запуска.
Такое же поведение возможно после прерывания установки паузы/отмены проекта,
когда статусы задач ещё остались `queued`. Отбор также исключает оставшиеся
в очереди дочерние задачи без подтверждённой привязки к плану.

## Изменение

Существующие условия допуска применяются в SQLite **до `LIMIT 50`**: владелец
доступен для записи, проект не на паузе/отменён, дочерняя работа привязана к плану
или не имеет привязки как обычная работа. Задачи проекта с уже выполняющейся
работой по-прежнему исключаются. Сохраняются порядок постановки, предел выборки,
лимиты очереди и один активный исполнитель процесса.

Это только отбор кандидатов. Существующие проверки `claim()`, актуального
состояния владельца, политики, бюджета и отмены остаются обязательными перед
исполнением. Запрос очереди не меняет состояния, права, checkpoints или файлы
пропущенных задач и не снимает блокировок. Новых повторов, модели, движка очереди,
интерфейса и миграций нет.

## Проверки

Для каждого отказа перед доступной задачей располагаются 50 недоступных записей:
блокировка Work, глобальная операция приватности, пауза проекта, отмена проекта
и отсутствие подтверждённой привязки к плану. Проверяется доступность следующей
работы и полная неизменность записей при чтении. Отдельно проверяются предел 50,
порядок очереди и исключение проекта с выполняющейся работой.

API-тест запускает настоящий координатор с тестовым ModelGateway и завершает
задачу другого владельца за 50 заблокированными записями. Защищённые задачи и
их блокировка сохраняются; модель получает только план и черновик доступной
работы. Платные обращения, серверная выкладка и управление ПК владельца не нужны.
