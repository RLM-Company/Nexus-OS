# Koswork: точечные улучшения интерфейса 18 октября

Продолжает предыдущий проход `KOSMORA_TARGETED_UI_2026-10-18_RU.md` по новому явному запросу владельца. Оболочка чата и сайдбар остаются заморожены за исключением перечисленных здесь изменений; правило закреплено в `apps/web/UI_RULES.md`.

## Реализовано

- Перетягиваемая горизонтальная шкала усилий в существующем выборе модели: Авто и поддерживаемые сервером low/medium/high. Локальный предпросмотр при движении, один PUT после отпускания, клавиатурное управление; при неудачном сохранении возвращается прежнее значение.
- Название режима Koswork. Внутреннее значение `work` и существующие беседы сохраняются.
- Переключатель «Чат / Работа» между названием нового чата и настройками/поиском. Сохраняет черновик, применяется при создании беседы; не появляется в чатах Studio, проектах, существующих чатах или отдельном пространстве Coscode.
- Векторный контур космонавта и кольца без заливки, внешней рамки и фонового квадрата.
- Регулируемая ширина панели 190–420 px с сохранением места для переписки. Перетягивание правой границы, стрелки клавиатуры, Home/End, двойное нажатие для сброса. Предпочтение сохраняется в браузере; мобильный вид сохраняет прежнюю навигацию и не затирает ширину десктопа.

## Применение подборки 24 референсов

Полная таблица решений остаётся в предыдущем отчёте. В этом проходе выбраны только уместные части:

| Референс                                                      | Применение                                                                                                    |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `zanwei/claude-model-selector`                                | Горизонтальная шкала усилий. Уровни определяет API; дополнительные выдуманные уровни не добавлены.            |
| `efferd/efferd-dashboard-2`                                   | Компактные карточки настоящих показателей использования в настройках аккаунта.                                |
| `kuratlielia/filter-toolbar`                                  | Поиск, фильтры состояния/типа, удаляемые активные фильтры и сброс истории запросов.                           |
| `isaiahbjork/leads-data-table`, `ruixen.ui/table-with-dialog` | Таблица фактических запросов и доступный диалог с деталями, возврат фокуса после закрытия.                    |
| `dillionverma/terminal`                                       | Вывод проверок Code: реальные stdout/stderr, фильтрация потоков, копирование, обозначение ограничения вывода. |

Настройки получили компактную внутреннюю навигацию по разделам и единые карточки. Источники данных, API, сохранение настроек, приватность и подтверждения публикации Code не изменялись. Денежные расходы и демонстрационные показатели не выдумываются. Референсы сайдбаров и новый главный экран не внедрялись.

Реализация адаптирует подходы из описаний и визуальных референсов, без запуска сторонних установочных команд и без добавления зависимостей. Это не заявление о переносе исходников всех компонентов 21st.dev.

## Проверки

- TypeScript и ESLint изменённых исходников web.
- 105 модульных проверок web, 10/10 проверок обработки таблиц.
- 14 браузерных сценариев: изменения этой задачи, голосовая кнопка, поиск, меню чатов, разделение Kosmora/Coscode/Work, Studio и полноценный сценарий review/check/publication Code на фикстуре.
- Дополнительно повторён сценарий Code с проверкой переключения stdout/stderr и настоящего вывода исполнителя.
- Проверены снимки 1280 px и 390 px: меню модели, шапка нового чата, ширина панели, настройки и аналитика.
- Тестовые базы получили уникальный timestamp в имени: повторно использованный PID больше не открывает базу старого запуска с другой схемой.

Платные AI-запросы в этом проходе не выполнялись. Полный исторический e2e-набор с устаревшими ожиданиями старых панелей этим отчётом не объявляется пройденным.

## Выкладка

Web-only сборка поверх текущего рабочего образа. Сохраняются прежние статические файлы для открытых вкладок, проверяется SHA сборки. Активация под maintenance lock с сохранением deployctl и автоматическим откатом при неудаче. API, владелец, Code executor, edge и база не обновляются.

Активен `cosmora-alpha-app:koswork-web-99cb00e`, исходники `99cb00e7823c95691c89c90f10d374d7bcd85e7e`, каталог `/opt/cosmora/releases/koswork-refinements-444652f`. Образ healthy; `/`, `/personal-settings`, `/code-agent` отвечают HTTP 200. Идентификаторы и время старта API, службы входа, Code executor и edge совпали до/после обновления и при повторной проверке. API остался `targeted-api-ca85c3d`.

При первом обрыве SSH сборка не сохранила образ и активация не началась: прежний healthy web продолжал работать. Повторный запуск с сохранением процесса завершился успешно. Проверено в авторизованной браузерной сессии: название Koswork, выбранная «Работа», горизонтальная шкала с текущими усилиями, изменение ширины 244→252→244, фактическая аналитика аккаунта и подробности запроса. Настройки модели и платные запросы при проверке не менялись.
