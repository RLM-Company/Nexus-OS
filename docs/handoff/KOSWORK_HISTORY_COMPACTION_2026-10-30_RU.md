# Kosmora/Koswork: проверяемое сокращение истории

Продолжение фундамента памяти PR #417. Блок работает локально, без дополнительного
платного вызова ИИ. Дизайн чата, сайдбар и логотип не менялись: добавлены только
элементы управления в существующую форму памяти.

## Что делает

Настройка каждого чата `compact_history` выключена по умолчанию. При включённой
памяти ранние завершённые текстовые сообщения сокращаются до точных целых цитат.
Сохраняются распознанные числовые условия, цели, решения, исключения и незавершённые
действия. Последние четыре группы сообщений остаются исходными до обычного отбора
по общему бюджету. Проверка происхождения и покрытия выполняется до сборки запроса.

Если обязательные цитаты не помещаются, потоковая и фоновая отправка останавливаются
до обращения к модели. Цитаты объединяются с ранее реализованной общей памятью;
источники остаются данными, не системными инструкциями и не разрешениями.

Это проверяемое извлечение, **не** LLM-сводка и не обещание помнить всё. Отбор важных
фраз эвристический. Старый код/вложения, ручная сводка и чрезмерная история пропускают
автоматический проход. Пакет пересобирается из текущих источников, не кэшируется.

## Измерение на тестовом примере

Локальная SQLite, настоящий API и сборщик запросов, mock-модель; 30 пар сообщений
с повторяющимися ответами, числом бюджета, датой, исключением и следующим шагом.
Измерение через `/history-compaction/preview`:

| Метрика                                        |        Значение |
| ---------------------------------------------- | --------------: |
| Сообщений вместе с вопросом проверки           |              63 |
| Сообщений в сокращённой ранней части           |              55 |
| Текст ранней части, UTF-8 байт                 |          84 830 |
| Проверенный пакет, UTF-8 байт                  |           4 056 |
| Найденных точных повторов                      |           1 103 |
| Обязательных распознанных фрагментов сохранено |           6 / 6 |
| Верхняя оценка входного контекста до / после   | 27 220 / 18 632 |
| Снижение этой оценки на данном примере         |          31,55% |
| Дополнительных вызовов модели                  |               0 |

До изменения уже действовало ограниченное окно истории: это сравнение реально
собранных ограниченных запросов, а не всей базы с маленьким пакетом. Значения не
являются реальными токенами/счётом провайдера или универсальной оценкой экономии.
Новые вложения и Skills не входят в предварительное измерение.

## Проверки

- Core: точные числовые условия, исключения, поздняя коррекция, незавершённая
  работа; подделка текста/хеша/роли/метаданных; переполнение; пропуски;
  распознанные секреты; границы объёма; пустой отменённый ответ.
- API: выключенное состояние, измерение без модели, реальная потоковая отправка,
  смена/исключение источника, изоляция владельцев, переполнение, ручная сводка,
  совместимость старого клиента и блокировка удаления данных.
- Фоновое исполнение: один вызов модели получает точные старые условия.
- Chromium: сохранение настройки, отчёт и открытие оригинала; реальная отправка
  с переполнением останавливается, оригиналы остаются, вызовов модели — ноль.
- Миграция и настройки проверяются на тестовых SQLite-базах. Живая приёмка
  качества ответов провайдера остаётся отдельной задачей.

Локально прошли: полный API — 716 тестов, полный Core — 336 тестов; DB —
115 тестов полного прогона и 16 тестов памяти после добавления отдельной проверки
настройки (включая один новый). Два сценария Chromium прошли и в development,
и на production-сборке. Privacy — 10 Node-тестов плюс интеграционный ZIP/удаление
и FTS smoke. Сборка всех девяти пакетов, форматирование и проверка секретов прошли.

## Подключение и ограничения

Нужна штатная миграция `0057_history_compaction` после `0056_context_memory`.
Изменения API/web и миграция подготовлены для будущей совместной выкладки.
Production-база, VPS и Windows-клиент владельца не менялись.

Автопрофиль, семантический/гибридный поиск, Drive/OAuth, пользовательское
хранилище и семантическая суммаризация этим блоком не реализованы.
Подробные пределы и правила — в [карточке памяти](../product/KOSMORA_MEMORY_2026-10-30_RU.md).
