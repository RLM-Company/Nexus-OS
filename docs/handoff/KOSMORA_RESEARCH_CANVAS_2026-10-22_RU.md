# Исследование → редактируемый Canvas

База: `e8eb073f68c63873c7b33e8e4334251a16d97182`, рабочая ветка `codex/integrate-work-presentations-20261017`. Изменения ограничены отдельным разделом исследований и общим компонентом открытия отчётов. Главный чат, сайдбар, бренд и глобальные стили не менялись.

## Сценарий

В завершённом, приостановленном, отменённом или ошибочном исследовании появилась кнопка «Открыть отчёт в Canvas». Она получает полный сохранённый Markdown только после нажатия, затем открывает существующий редактор. Ответ модели, цитаты, исходные выдержки, статусы источников, ограничения, идентификатор исследования и даты сохраняются в тексте отчёта. Частичный результат остаётся явно частичным по исходному статусу. Подготовка копии не запускает поиск, сеть к источникам, синтез модели или создание артефакта.

До явного «Сохранить версию» работает существующий локальный черновик Canvas, разделённый по подтверждённому владельцу и проекту. Далее доступны прежние версии, сравнение, экспорт Markdown/DOCX/PDF и защита конфликтов. Сохранённая редакторская копия не меняет исследование. Копия связывается с исходным снимком через идентификатор/дату в содержимом и существующий хеш черновика; это обычный Canvas с `manual` provenance, отдельная таблица связей или live-синхронизация не добавлялись.

При смене выбранного отчёта или его даты прежняя загрузка отменяется; поздний ответ не открывает другой проект. Повторное нажатие блокируется на время подготовки. Лимит Canvas 512 КиБ и запрет NUL сохраняются. Сетевая ошибка оставляет исследование и прежний черновик доступными. Ошибка устаревшей даты требует обновления отчёта.

## API и совместимость

Существующий `GET /api/v1/research/:id/export/md|html` сохраняет owner-проверку и отдаёт strong ETag по SHA-256 фактического тела. Необязательный `If-Match` проверяет этот хеш; `X-Research-Updated-At` проверяет дату, которую видел интерфейс. Несовпадение возвращает 412. Дата сама по себе не является уникальным хешем; отдельная проверка покрывает изменение текста с сохранением прежней миллисекунды. Прежние скачивания без заголовков продолжают работать. Markdown теперь содержит ID исследования.

Новых миграций, зависимостей, провайдеров, прав и автоматических AI-запросов нет. Сохранённый Canvas участвует в существующих экспорте и удалении данных владельца. Если SearxNG не подключён, новые исследования по-прежнему недоступны, но сохранённые отчёты можно копировать.

## Независимые проверки

11 API-проверок исследований прошли: реальный managed SQLite, текст/цитаты экспорта, owner isolation, strong hash, устаревшие условия, различие форматов, изменение в ту же миллисекунду и отсутствие созданных model runs/Canvas при чтении.

Шесть Chromium-сценариев прошли одним прогоном: три существующих Files/Canvas сценария и три новых research сценария. Проверены настоящее HTTP/SQLite сохранение Canvas, v1/v2, повторное открытие после reload, полный Markdown download, отсутствие model POST, устаревший отчёт без создания артефакта, отмена загрузки и разделение проектов. Сами research-ответы в браузерном прогоне заданы фикстурами; реальная работа поиска/провайдера этим не подтверждается. Скриншот `qa/research-canvas.png` показывает тестовый отчёт.

Типы contracts/core/db/api/web, scoped ESLint, secret scan и diff-check прошли. Первый запуск браузерного сервера не уложился в 60 секунд при параллельной компиляции; повторён последовательно. Исправлены два неточных тестовых ожидания, длинному сценарию экспорта дано 60 секунд на тест, итог 6/6. Production build и выкладка фиксируются после отдельной проверки.
