# Экономия контекста и подбор источников — 2 ноября 2026

## Объём

Владелец выбрал этот блок после разбора AI Engineering Hub. Код основан на
`6383599fb169b423540ff4813c0298e35b5fac22`; рабочая ветка
`codex/context-source-selection-20261102`. Она продолжает цепочку PR #429;
справочную ветку с чужими исходниками в приложение не сливали.

## Результат

- В исполняемом контексте буквальный `source.quote`, совпадающий с `text`,
  передаётся один раз. Сохранённая запись, её оригинал и версия не меняются.
- Перекрывающиеся выдержки истории сворачиваются при одинаковом происхождении.
  Различающиеся роли, ссылки, версии, хеши, неповторяющиеся цитаты и конфликтующие
  порядковые номера сохраняются отдельно. Большие группы имеют ограниченную
  проверку включения; точные повторы обрабатываются отдельно.
- Маленькая обязательная выдержка не поглощается большим необязательным
  фрагментом. Нехватка места под действительно обязательное останавливает запрос.
- Необязательная память подбирается по текущему вопросу, включая короткие числа.
  Исходный вопрос не обрезается. Подсчёт полного JSON остаётся точным в UTF-8.
- Исправлена прежняя дедупликация хранилища только по нормализованному тексту:
  одинаковые слова пользователя/ассистента, факта/гипотезы и разные числовые
  обозначения больше не превращаются в одну запись контекста.
- Подключены ChatService, Manager Work и локальный исполнитель Work. Аудит
  фиксирует фактически переданный пакет и его источники штатным механизмом.

## Проверки

- 39 тестов core: отбор, упаковка, история, обычный запрос и квитанция памяти.
- 19 тестов хранилища: источники, владельцы, роли, типы и точные числа.
- 121 тест API: память чата, контекст, Manager Work и computer-control.
- Сборка API и всех восьми входящих пакетов; typecheck core/db/API.
- ESLint изменённых файлов, форматирование и штатная проверка секретов.

Синтетический benchmark воспроизводится командой `pnpm bench:context-selection`.
[Сохранённый отчёт](../reviews/context-selection-benchmark-2026-11-02.json):
108 элементов / 52 509 байт → 12 элементов / 8 468 байт, сокращение **83,87%**.
На этом наборе проверены буквальное покрытие всех исходных выдержек, все
независимые ссылки и обязательный статус. Второй случай проверяет выбор
релевантного источника при бюджете 833 байта.

В наборе намеренно много повторов. Это не замер реального расхода токенов,
смысловой памяти модели, ускорения ответа или экономии денег. Новых платных
запросов и обращений к внешним сервисам benchmark не делает.

## Выпуск и ограничения

Изменения подготовлены в отдельном worktree; работающая копия приложения и VPS
в этом блоке не перезапускались. Миграций, новых зависимостей, настроек тарифа,
изменений интерфейса и новых разрешений инструментов нет. Живая приёмка первого
этапа остаётся отдельной задачей.

Подбор остаётся лексическим. Семантический поиск, постоянные сводки, граф памяти,
ленивая загрузка схем инструментов и вынесение больших tool-результатов в файлы
не входят в выполненный блок. Их очередь и материал будущего курса находятся в
[плане внедрения](../product/AI_ENGINEERING_HUB_ADOPTION_RU.md).
