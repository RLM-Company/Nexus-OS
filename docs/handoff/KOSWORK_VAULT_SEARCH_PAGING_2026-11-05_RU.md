# Koswork: постраничный поиск локальных материалов

Пакет поверх PR #445. Поиск по тексту/имени возвращает до восьми совпадений и
next_search_path. Продолжение требует точные mode/query. Курсор связывается
SHA256 с запросом, режимом, текущим списком источников и текущим grant.
Добавление/удаление источника или новое разрешение требуют свежего поиска,
а не незаметного пропуска/дублирования записей. Продолжение readonly.

Локальный search принимает ограниченные cursor/maxResults; после исчерпания
4 MiB бюджета возвращает индекс ещё не просмотренного подходящего источника,
чтобы следующая страница могла продолжить. Сохраняется ограничение 1 MiB
просматриваемого оригинала и ограничения Office extraction; limited остаётся
честным признаком неполного покрытия. Это не all-content/semantic search.

Snippet ограничен 500 JSON/UTF-8 bytes с целой Unicode-границей и явным
snippet_truncated. Ссылка позволяет прочитать исходник без такого сокращения.
Полный ответ сохраняет 14000-byte guard, scope/owner/revoke/hash проверки.
Новые права, UI, dependencies, migrations и платные вызовы не добавлены.

Проверки: 40 focused tests; полный desktop 271 tests: 270 passed, 0 failed,
1 штатный Windows-only skip. 23 результата обоих режимов без дублей/потерь,
4 MiB continuation, stale query/source/grant, многоязычные имена/выдержки,
точное чтение источника. Secrets, formatting и whitespace прошли.
Live provider, Windows install и VPS не проверялись.
