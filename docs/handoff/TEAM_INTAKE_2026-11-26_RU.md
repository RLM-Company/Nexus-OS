## Пересечения и границы

- Остаются миграции `0072_project_correction_rules` и `0073_project_sources`. Запись квитанции выполняется сервером на основании фактического запуска. Историческая квитанция Work содержит ссылки и хеши найденных материалов без копирования их текста. Параллельная ветка #671 предлагает клиентский `POST /sources/run` и дублирующую миграцию. Эти части не входят в кандидат.
- [#665](https://github.com/RLM-Company/Nexus-OS/pull/665) остаётся Draft. Предложенный маршрут выбирает DAG по владельцу и ID, а правила по проекту из URL. Для безопасного использования нужна проверяемая связь DAG с проектом и применение правил внутри обычного исполнения с сохранением результата. Поддерживаемое правило сравнения поставщиков уже применяется внутри Work.
- [#673](https://github.com/RLM-Company/Nexus-OS/pull/673) остаётся предложением контракта. При чтении сохранённого состояния маршрут восстанавливает пустые историю, результат и состояние извлечения. `result_ref` указывает на задачу, поэтому сам по себе не подтверждает готовый файл. Канонический core уже в #670. Для приёмки интеграции нужен переход из действующего рантайма с реальными сохранёнными материалами, состоянием и ссылкой на проверенный результат.
- Живой вызов модели, внешний Draft PR, Windows-клиент и визуальный рендер документов остаются отдельными проверками. Браузерные тесты Office проверяют экспортированные байты на фикстурах.
