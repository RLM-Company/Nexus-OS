# Koswork: продолжение оглавления Markdown

Пакет поверх PR #444. Оглавления теперь возвращают start_utf16, next_offset и
next_outline_path; агент читает продолжение через workspace_read. Ссылки содержат
immutable source SHA256. Невалидная позиция внутри строки/CRLF отклоняется,
новая страница всегда продвигается или завершает обход. Grant/owner/revoke
проверяются на каждом чтении, права и UI не меняются.

Сохраняются пределы 40 заголовков/6500 промежуточных JSON bytes и 14000 bytes
полного ответа. Мягкое окно — 256000 UTF-16 с завершением текущей строки,
поэтому длинная строка не создаёт зацикленный курсор. Жёсткий размер оригинала
по-прежнему 10 MiB. Для правильных fenced code blocks каждый запрос повторно
разбирает префикс: постоянного индекса/ускорения больших документов не заявляем.
Эта версия позволяет последовательно просмотреть весь оригинал в его пределах,
а не только первые 256000 символов. ATX-only ограничения прежние.

Проверка: 37 focused tests; полный desktop 268 tests, 267 passed, 0 failed,
1 штатный Windows-only skip. Обход 105 заголовков без повторов/потерь, fence через
границу страницы, длинная строка без остановки прогресса, CRLF-invalid cursors,
переход к разделу 94 через opaque paths и отказ после revoke. Форматирование,
secrets и whitespace проверены. Нет live модели/Windows install/VPS/build claim.
