# Koswork Office: отложенные изменения представления

В этой поставке добавлены только функциональные контролы в существующем разделе
файлов. Чат, сайдбар, логотип, палитра, типографика и глобальные стили сохранены.

Для отдельного согласования с владельцем: визуальный макет страниц/слайдов,
настраиваемые ширины столбцов, специализированная сетка таблицы и оформление
сравнения версий. Сейчас доступны текст/адреса, типы ячеек, явные «Было/Будет»
и проверенная копия; это не WYSIWYG и не обещание полного визуального соответствия.
