# Vault: поиск с точной позицией в оригинале

Пакет поверх PR #442. Поиск сравнивает NFKC/lowercase строки, но раньше искал
позицию первого терма в ненормализованной копии. Для compatibility-символов и
составных букв результат мог вести к началу большого документа.

Позиция нормализованного совпадения теперь переводится в начало исходного
Unicode grapheme через Intl.Segmenter. Цитата и содержимое не нормализуются.
Конец snippet не разрывает surrogate pair. Пустой запрос и более 12 термов
отклоняются, а не превращаются в поиск всего или молчаливое усечение запроса.
Лимиты сканирования, оригиналы, grants и readonly source path сохранены.

Проверки: 30 focused Vault tests passed; полный desktop 261 tests, 260 passed,
0 failed, 1 штатный Windows-only installer skip. Есть реальные временные файлы
с совпадением за пределами первой страницы: ①/１２３, ﬃ, Cafe + combining accent,
İstanbul; проверяется оригинальная цитата, позиция и последующий fragment read.
Secret scan, formatting и whitespace прошли. Это не семантическое ранжирование,
не новая функция загрузки и не live Windows/VPS приёмка.
