## Рекомендуемый объём (предмет решения)

1. **Базовый уровень** — переиспользовать текущий Web Speech API: готовые команды
   (открыть раздел, найти чат, начать диктовку, озвучить ответ) как command intent
   поверх существующего `voice-assistant.tsx`; без новых зависимостей.
2. **Агентный уровень** — отдельным согласованным шагом: свободное поручение
   выбранному режиму (computer/browser/work) через Koswork, с состояниями
   listening/processing/executing/speaking и interrupt/stop через существующие
   stop/takeover механизмы.
3. **Адаптер созвонов** — отдельный адаптер с заранее заданными правами; без
   доступа к микрофону/камере владельца без явного разрешения.
4. **Offline-основа** — только после проверки лицензии выбранной модели и
   реальной сборки в Windows-клиенте.
