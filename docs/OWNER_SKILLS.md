# Приватные Skills

`/skills` хранит текстовые инструкции владельца: создание, просмотр, редактирование с новой неизменяемой версией, восстановление ранней версии как новой и удаление. Данные доступны только этому владельцу; `expected_version` отклоняет устаревшее сохранение. Лимиты: 50 инструкций, 20 версий, 20 000 символов на инструкцию.

API: `GET/POST /api/v1/owner-skills`, `GET/PUT/DELETE /api/v1/owner-skills/:id`, `POST /api/v1/owner-skills/:id/restore`. Записи блокируются во время privacy fence, включены в экспорт и удаление данных аккаунта. Миграция `0040_owner_skills` следует за `0039_notification_center`.

Предпросмотр показывает буквальный текст без рендеринга HTML. Эти инструкции не подключаются к модели, инструментам или правам доступа. Прежний mock-каталог контрактов оставлен как пример, без исполнения и установки. Публикация общего Skills marketplace и запуск кода не входят в этот блок.

Для ручного обмена доступен JSON-пакет `kosmora.skill.v1`: скачать последнюю версию через `GET /api/v1/owner-skills/:id/package`, импортировать через `POST /api/v1/owner-skills/import` или кнопки на странице. Пакет содержит текст, `execution: disabled`, пустой список `permissions` и SHA-256 для обнаружения случайной порчи. Контрольная сумма не удостоверяет автора; импорт отклоняет изменённый текст, дополнительные поля, запрашиваемые разрешения и исполняемые пакеты. Выбор файла выполняется локально, размер ограничен 64 КБ в браузере и полями API. Импорт создаёт новую приватную инструкцию, не устанавливает программный пакет.
