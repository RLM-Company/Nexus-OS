# BIZ-069 — отчёт «Что изменилось»: сдача

**Ветка:** `feature/koswork-version-change-report`. **База:** `main` `8ed117f8`.
**Граница:** переиспользуемый движок + тесты + пример. Общий каталог и UI
Koswork подключает Codex — здесь не трогались.

## Реализация

`packages/core/src/version-change-report.ts` (экспорт добавлен в `index.ts`):

- **Вход:** две версии данных в формате `kosmora.studio.data`, ключ
  сопоставления (1-based колонки на каждой стороне) и, при наличии,
  предыдущий Markdown-отчёт.
- **Переиспользование:** зовёт существующий `compareTables` с
  `alignment: {kind:"key"}` и `include_values: true`; не создаёт второй
  алгоритм сравнения.
- **Выход:** `markdown` (скачиваемый файл) + структурированные поля
  `duplicate_keys`, `uncomparable`, `definition_changes`,
  `affected_conclusions`, `summary`, `source` (SHA256 обеих версий).
- Дубли ключей и пустые ключи выносятся в явные списки; сравнение
  продолжается на дедуплицированных копиях, поэтому остальные изменения не теряются.
- Смена периода, единиц, методики или схемы — отдельный блок
  «Определения и методика» с предупреждением, что числовые сравнения могут
  быть некорректными.
- Из предыдущего отчёта переносятся только строки с ссылками на записи
  (`[S1]`, `row`, `строка`, `запись`) — новые выводы не выдумываются.
- Ограничения: отчёт <= 1 МБ, детерминированный порядок, 200 изменений
  на страницу (флаг `truncated` в структуре).
