## Как принять новый пакет

1. Сохранить исходный файл или полный текст без изменения нумерации,
   с источником и контрольной суммой.
2. Проверить фактическое количество пунктов. Сопоставить их с существующим
   кодом и уже принятыми поставками; не подменять новый список PR #330.
3. Для каждого пункта записать исходный ID, критерий приёмки, зависимости,
   состояние, коммит реализации и свидетельство проверки. До такой проверки
   состояние — «не проверено», а не «готово».
4. Исполнять незавершённые пункты на актуальной интеграционной базе с
   сохранением существующих owner/CAS/budget/privacy границ и
   [UI_RULES.md](../../apps/web/UI_RULES.md).

При появлении исходника обновить GEMINI-132 в этом реестре. Не создавать
вымышленные 132 задачи и не включать их автоматически в выполненный объём.
