## 3. Явное разделение полностью автономных механизмов и адаптеров к внешним сервисам

| Подсистема / Модуль | Режим работы в локальном рантайме | Требования для внешнего продакшен-контура | Поведение при отсутствии внешнего сервиса |
| :--- | :--- | :--- | :--- |
| **GitHub Issues / Pull Requests (`F069`, `F070`)** | Реальный HTTP-клиент (`fetchImpl` / `globalThis.fetch`) с проверкой схемы ответа, кодов `401/403`, `429` и таймаута `AbortController` | Токен `GITHUB_TOKEN` (или `configureGitHubAdapter({ token })`) и сетевой доступ к `api.github.com` | Выбрасывает детерминированную ошибку `ExternalConnectorError("UNCONFIGURED_ADAPTER")`; никогда не генерирует фиктивный номер PR |
| **Песочница исполнения кода (`F074`, `F075`, `F132`)** | Реальный изолированный подпроцесс `spawnSync` (`python3 -I -B`, `node`, `bash --noprofile --norc`) во временной директории `/tmp/kosmora-sbx-*` с очищенным `env`, лимитом времени и байтов вывода | Для режима `isolation_mode: "oci_container_required"` требуется установленный демон `docker` или `podman` | В режиме `subprocess_restricted` работает штатно; при запросе `oci_container_required` без установленного OCI-рантайма выбрасывает `SandboxIsolationUnavailableError` |

| **Вебхуки событий (`F148`, `dispatchSignedWebhook`)** | Формирует криптографическую подпись `HMAC-SHA256` со статусом `status: "created"`, `delivered: false`; при вызове `deliverSignedWebhook(delivery, transport)` выполняет реальную отправку | Настроенный HTTP-транспорт (`WebhookHttpTransport` / `fetch`) и доступный URL получателя | Без вызова транспорта остаётся в состоянии `status: "created"` (`delivered: false`); при ошибке сети/HTTP 5xx переходит в `status: "failed"` |
