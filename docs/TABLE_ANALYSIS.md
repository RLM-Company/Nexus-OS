# Серверный анализ сохранённых таблиц

Вычисления работают с точной сохранённой ревизией таблицы проекта. Они не вызывают
модель, не выполняют SQL или выражения из ячеек и не изменяют данные. Интерфейс этим
блоком не меняется; API предназначен для последующего подключения к инструментам.

База URL: `/api/v1/projects/:projectId/tables/:id/revisions/:version`.
Нужна обычная сессия владельца и доступ к проекту. Чужая таблица, чужой проект и
артефакт другого типа дают 404. Перед расчётом проверяется SHA-256 исходной ревизии;
повреждение даёт 409 без выдачи содержимого. Ответы имеют `private, no-store`.

| GET                                   | Результат                                                                                                                                                                                                                            |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/analysis?scope=view`                | Число строк, точные дубликаты выбранных ячеек, пропуски, число различных непустых значений; для числовых столбцов — валидные/невалидные значения, min/max, сумма, среднее, медиана и стандартное отклонение генеральной совокупности |
| `/rows?scope=view&offset=0&limit=100` | Страница до 500 строк, исходные номера строк, выбранные столбцы, общее число и следующий offset                                                                                                                                      |
| `/export?scope=view&format=json`      | Все строки результата с метаданными столбцов и точными строковыми ячейками                                                                                                                                                           |
| `/export?scope=view&format=csv`       | Все строки результата в CSV с BOM, экранированием кавычек/переносов и защитой от формул                                                                                                                                              |

`scope=view` по умолчанию применяет **сохранённые** фильтры, сортировку и выбранные
столбцы. `scope=all` берёт всю таблицу в исходном порядке. Запрос не изменяет настройки
и не может задать произвольный код. Все расчёты охватывают выбранные строки целиком,
без семплирования. Номер `source_row` — 1-based номер строки данных, без заголовка.
Дубликаты считаются по точному равенству ячеек выбранных столбцов, включая пустые строки.

Числа разбираются только в явно числовых столбцах. Поддерживаются десятичная точка/
запятая и согласованные пробельные разделители тысяч, как в текущем Studio. Неоднозначная
запись, экспонента и значения за пределом MAX_SAFE_INTEGER не угадываются. Текстовые
идентификаторы `001` остаются текстом. Пустые и невалидные значения не участвуют в
числовой статистике. Если сумма выходит за надёжный диапазон, она возвращается как
`null` с `sum_reliable:false`; это не бухгалтерская десятичная арифметика.

Существующие операторы Studio `greater` и `less` включают граничное значение. Равные
значения сохраняют исходный порядок, пустые/невалидные числа стоят в конце даже при
убывающей сортировке. При невалидном числовом пороге `view` возвращает 400, а `all`
можно использовать независимо от фильтра.

JSON использует индексы столбцов и массивы ячеек: одинаковые заголовки не затирают
друг друга. CSV — экспорт для просмотра: опасные текстовые префиксы формул получают
апостроф, а Excel может переинтерпретировать текстовые числа. Для точного переноса
используйте JSON либо прежнее скачивание workspace. Размер готового экспорта ограничен
32 МБ. `x-table-version`/`x-table-sha256` обозначают исходную ревизию,
`x-export-sha256` — точные байты выгрузки.

Используются существующее хранилище Canvas и его лимиты. Новых таблиц БД, миграций,
внешних библиотек, платных запросов и фоновых задач нет.
